# UAV Swarm Pursuit / Encirclement Literature Map

Long-term literature-mapping workspace for rebuilding a systematic understanding of:

**multi-agent / UAV swarm control → encirclement → pursuit–evasion → learning-based pursuit/encirclement → CoCap-near problems**.

Workflow: **Search → Screen → Read**.

The project aims to produce a structured map of method genealogy, assumptions, problems, frontier bottlenecks, and CoCap's research position—not merely a large PDF collection.

## Canonical source of truth

Read these first in every MASTER session:

- `PROJECT_PROTOCOL.md`
- `LITERATURE_MAP.md`
- `SEARCH_LOG.md`
- `PAPER_INDEX.csv`
- `READING_LEDGER.md`

Long notes belong under `notes/`. Canonical files remain compact and structured.

## Roles

- **MASTER**: sole merger/writer of canonical files.
- **Search agents**: maximize recall and return standardized handoffs.
- **Screening agents**: classify candidates as `MUST READ / MAP / ARCHIVE`.
- **Reading agents**: deeply read selected papers and write standardized notes.
- **Human researcher**: validates important claims, manages PDFs/Zotero, and makes final research judgments.

PDFs should normally stay in Zotero / the active ChatGPT Project rather than be bulk-committed here.
