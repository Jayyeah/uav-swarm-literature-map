# READING NOTE — P0019 — Hamilton–Jacobi Formulation for Reach–Avoid Differential Games

## 1. Paper positioning
- Problem: [原文] 对带 competing inputs、nonlinear dynamics 与 state constraints 的 target-hitting game，严格定义并计算 **reach-avoid set**；同时区分 terminal-time reach-avoid 与 any-time reach-avoid。
- Main predecessors: [原文] viability/capture-basin 路线（Aubin/Cardaliaguet 等）、Lygeros reachability/minimum-cost、Mitchell–Bayen–Tomlin (2005, P0018) time-dependent reachable sets、早期 state-constrained reach-avoid formulations。
- Why this paper was needed: [原文] 早期 state-constrained reach-avoid PDE formulation 可能产生 discontinuous Hamiltonian/value-function difficulties。本文构造连续 value function/Hamiltonian，并证明其是 variational HJ equation 的唯一连续 viscosity solution，从而可稳定使用 level-set numerical tools。
- Map role: [AI判断] R-PE-01 中最重要的**语义锚点**：告诉我们“保证可达且全程避开失败集合”到底是什么量词命题，以及为什么它不同于普通 backward reachable set。

## 2. Problem setting
- Agents / targets: [原文] 不限定为 pursuer/evader point masses；一般 continuous dynamic game `ẋ=f(x,u,v)`，其中 `u` 是 controller/第一方，`v` 是 adversarial disturbance/第二方。（Sec. II-A, PDF p. 2 / IEEE p. 1850）
- Dynamics: [原文] `f` 对 state Lipschitz、对 inputs continuous；`U,V` compact；因此给定 measurable inputs 存在唯一 trajectory `φ(τ,t,x,u(·),v(·))`。（Assumption 1, Eq. (1), p. 2）
- Action space: [原文] measurable input signals `u:[t,T]→U`, `v:[t,T]→V`。
- Sensing / strategy information structure: [原文] 第一方采用 **non-anticipative strategy** `γ:V_[t,T]→U_[t,T]`：若两个 opponent inputs 在 `[t,s]` 几乎处处相同，则 `γ[v]` 在 `[t,s]` 也必须相同。它可以响应对手当前/过去行为，但不能看未来。（Sec. II-A, p. 2）
- Communication / centralized: generic game formulation，不定义机器人通信图。
- Map / obstacles: [原文] state constraint function `h(x)` 可编码 forbidden/obstacle region；case study 用固定障碍演示。
- Target behavior: target set由 `l(x)` 的零下水平集编码。
- Speed ratio / capture radius: generic theory 无固定 speed-ratio/capture-radius 假设；若应用到 PE，需在 `f,l,h` 中编码。
- Termination: terminal-time variant 要在固定 `T` 到达 target；any-time variant允许在 `[t,T]` 内某一时刻命中 target，并只要求在命中之前不进入 avoid set。
- Solution object: reach-avoid set as value-function zero sublevel set。
- Scalability: [原文] grid-based level-set 计算随 state dimension 指数增长，case study 明确指出 curse of dimensionality。（Sec. IV-C, PDF p. 8 / IEEE p. 1856）

## 3. Core idea
### Plain-language summary
[原文] 普通 reachability 只问：“我能不能在时间窗内到 target？”Reach-avoid 多了一个沿途的硬条件：“而且在到达之前，轨迹不能进入 avoid/unsafe set。”有 adversarial input 时，“能”不是存在一条幸运轨迹，而是：**存在一个 non-anticipative controller strategy，使得对任意对手 input 都能满足 reach + avoid。**

[AI判断] 对 CoCap，若把 evader 的目标设为“到达 escape/goal region，同时避开 capture set”，那么 reach-avoid value 比 raw distance、普通 reachable set 或 Apollonius distance 更接近“escape feasibility”的本体定义。

### Mathematical / algorithmic mechanism
#### Target and avoid encoding
[原文] 两个 bounded Lipschitz functions：
- `R = {x∈R^n | l(x)≤0}`：closed target set；
- `A = {x∈R^n | h(x)>0}`：open avoid/forbidden set。（Sec. II-A, p. 2）

因此“安全”条件是 `h(x(τ))≤0`。

#### Terminal-time reach-avoid set — Eq. (2)
[原文] Sec. II-B 定义：

`RA(t,R,A) = { x | ∃γ∈Γ_[t,T], ∀v(·)∈V_[t,T],`
`                    φ(T,t,x,γ[v],v)∈R`
`                 ∧ (∀τ∈[t,T], φ(τ,t,x,γ[v],v)∉A) }`.  (Eq. (2), PDF p. 2)

量词结构必须按顺序读：
- `∃γ`：存在一个 non-anticipative strategy；
- `∀v`：面对任意 adversarial input；
- 固定终点 `T` 在 `R`；
- 整个 `[t,T]` 都避开 `A`。

#### Terminal-time value — Eq. (3)
[原文]

`V(x,t) = inf_{γ∈Γ} sup_{v∈V} max{`
`          l(φ(T,t,x,γ[v],v)),`
`          max_{τ∈[t,T]} h(φ(τ,t,x,γ[v],v)) }`.  (Eq. (3), p. 2)

物理意义：第一项衡量 terminal target violation，第二项取整条 trajectory 上最坏的 state-constraint violation；外层 `max` 表示两者必须同时满足。controller 使它最小，adversary 使它最大。

[原文] **Proposition 1:**

`RA(t,R,A) = {x | V(x,t)≤0}`。（p. 2）

因此 `V=0` 是 reach-avoid feasibility boundary；`V<0` 在定义/尺度固定时可解释为可行侧 margin，`V>0` 为无法保证侧。

#### HJ variational equation — Eq. (4)
[原文] `V` 是下面 variational equation 的唯一 viscosity solution（Theorem 1, Sec. III-B）：

`max{ h(x)-V(x,t),`
`     ∂_t V(x,t) + sup_{v∈V} inf_{u∈U} [∂_x V(x,t) f(x,u,v)] } = 0`,

terminal condition：`V(x,T)=max{l(x),h(x)}`。（Eq. (4), pp. 2, 4–6）

其中 Hamiltonian 是 `H(x,p)=sup_v inf_u p^T f(x,u,v)`。

#### Any-time reach-avoid — Eq. (5)
[原文] Sec. II-C 定义更适合“在时间窗内随时到达”的集合：

`RA~(t,R,A) = {x | ∃γ, ∀v, ∃τ_1∈[t,T],`
`                        φ(τ_1,...)∈R`
`                     ∧ ∀τ_2∈[t,τ_1], φ(τ_2,...)∉A }`.  (Eq. (5), PDF p. 3 / IEEE p. 1851)

这里命中时间 `τ_1` 可以依赖 opponent realization，但必须在命中前始终满足 avoid constraint。

[原文] 作者通过 augmented “freezing” input `a∈[0,1]`：

`f~(x,u~,v)=a f(x,u,v)`  (Eq. (6))

与 pseudo-time `σ(τ)=t+∫_t^τ a(s)ds` (Eq. (7))，把 any-time hit 变成 augmented terminal-time problem。

**Proposition 2:** `RA~(t,R,A)={x | V~(x,t)≤0}`。（p. 3）

#### Any-time HJ equation — Eq. (11)
[原文] **Theorem 2**：`V~` 是唯一 viscosity solution：

`max{ h(x)-V~(x,t),`
`     ∂_t V~(x,t) + min{0, sup_v inf_u [∂_x V~(x,t) f(x,u,v)]} }=0`,

terminal `V~(x,T)=max{l(x),h(x)}`。（Eq. (11), PDF p. 6 / IEEE p. 1854）

`min{0,H}` 来自 freezing input：当继续演化不能改善 reach-avoid value 时，可以“冻结”到达时刻。

## 4. Method details
### PE papers
- Game formulation: [原文] controller vs adversarial input zero-sum target-hitting with state constraints。
- Payoff: [原文] max of terminal target violation and worst pathwise constraint violation，then inf–sup over strategy/input。
- Winning/capture region: [原文] zero-sublevel set of `V` or `V~` 是 guaranteed reach-avoid set。
- Equilibrium / HJI / other geometry: generic HJ variational inequality；不是 Apollonius geometry。

### What this set is **not**
- `reach-avoid set ≠ ordinary backward reachable set`: [AI判断] 后者可只编码“能到 target”，不必同时满足独立的 avoid/state constraint。P0019 正是为 state-constrained target hitting 建模。
- `reach-avoid set ≠ dominance region`: [AI判断] dominance region 通常是物理空间中的“谁先到某点”集合；P0019 的 set 在一般 **joint/state space** 上由策略量词与 trajectory constraint 定义。
- `reach-avoid set ≠ capture region`: [AI判断] capture region 必须先指定“capture”是 target 还是 avoid、谁是 controller、谁是 adversary、capture radius/terminal semantics。仅凭 HJ level set 名称不能自动叫 capture region。
- `reach-avoid set ≠ winning region in every PE paper`: [AI判断] 它可被用来构造某一方 winning set，但方向取决于 `R/A` 与 min–max orientation。

## 5. Evidence
- Baselines: theoretical comparison to earlier state-constrained reachability formulations；主要贡献是 value/Hamiltonian continuity + viscosity characterization。
- Metrics: theoretical set correctness；case study 展示 computed set。
- Simulation: [原文] underactuated underwater vehicle with current disturbance and fixed obstacles；target/obstacles 用 signed distance functions 编码。（Sec. IV, pp. 6–8）
- Real experiment: 无。
- Scalability/generalization: [原文] model class很一般，但 level-set grid 随维度爆炸；Table I 的示例从 3D 到 4D 显著增加 time/memory，只用于说明趋势，不应外推为通用复杂度常数。（p. 8）

## 6. Limitations
### Author-stated [原文]
- future work 包括 time/control-dependent obstacle function；
- 从 value derivative 数值构造 optimal control 对 numerical errors 很敏感；
- grid level-set suffered curse of dimensionality。（Conclusion, pp. 8–9）

### Evidence-visible [原文 + AI判断]
- guarantee 依赖已知 dynamics、compact input sets、Lipschitz assumptions 与指定 non-anticipative information structure。
- “margin” 的数值大小受 `l,h` 的编码/scaling 影响；只有 sign/zero level set 具有直接集合语义，跨任务直接比较绝对值需要 normalization。

### Our inference [AI判断]
- 在 CoCap 中，直接对 `N` 架 UAV + 多目标 joint state 做 HJI 不现实；合理用法是 **low-dimensional teacher / auxiliary label / safety prior**。
- local sensing 下，真实 state 不完全可知，严格 `V(x,t)` 需变成 belief/robust/probabilistic estimate；否则“certificate”只是 oracle upper bound。

## 7. Literature lineage
- Important predecessors:
  - viability/capture basin: Aubin; Cardaliaguet et al.
  - Lygeros (2004) reachability/minimum-cost without the same reach-avoid construction。
  - Mitchell, Bayen & Tomlin (2005, P0018): HJI backward reachable sets / any-time reachability foundation。
- Same-era alternatives: ellipsoidal state-constrained reachability (mainly linear systems), earlier hybrid reach-avoid operators。
- Later extensions/use in this project:
  - P0024 uses a 4D pairwise HJI reach-avoid set as 1v1 winner certificate, then maximum matching。
  - P0016 treats this HJI line as one branch alongside analytical geometry。

## 8. Relation to CoCap
- Closest similarities: adversarial target 在有限时间/空间中试图 escape，pursuers 要让 target 的 reach-avoid objective 失效。
- Fundamental differences: P0019 是 generic known-model full-state dynamic game；CoCap 是 local/partial observation、multi-UAV multi-target、online role switching。
- Does it cover a candidate novelty?: [AI判断] 它覆盖“用 value function 表示 guaranteed reach-avoid feasibility”这一理论原语，但不覆盖 learned decentralized coalition recruitment。
- Directly reusable ideas:
  1. **escape feasibility margin**：把 evader 的 goal-entry 当 `R`、capture/obstacle failure 当 `A`；`V~≤0` 表示 evader 有 guaranteed reach-avoid strategy（在选定 game orientation 下）。
  2. 以 `V~≈0` 作为 curriculum hard cases / evaluation boundary，而不是只按 Euclidean distance 难度划分。
  3. 将低维 HJI value 作为 critic auxiliary target 或 offline teacher。
- Non-transferable assumptions: exact state、exact dynamics、known opponent input bounds、tractable low-dimensional state、strategy-class assumptions。
- New research questions exposed: 如何把 HJI/reach-avoid margin 蒸馏成只用 local observation + neighbor messages 的 learned robust certificate？

### Potential CoCap implementation candidates
1. **Auxiliary capturability head**：输入 local coalition-target features，预测 oracle low-D `V_RA` 的 sign/margin；主 RL policy 不必显式解 PDE。
2. **Support gate**：对当前 target 的 estimated escape margin 接近/低于阈值时招募 support；不是按 agent-target distance 排序。
3. **Evaluation**：报告 policy 对 teacher barrier 近邻状态的 false-positive（以为可捕实际不可保证）与 false-negative。

### Sign convention for CoCap
[AI判断] 若把 **evader** 作为 reach-avoid controller，`V_escape≤0` 表示它可保证 escape；对 pursuer 来说这反而是“坏”。因此可以定义一个 monotone capturability score，例如 `C=-V_escape` 或直接用 signed classification（`escape-feasible` vs `not guaranteed`），但必须在实现中固定 `l,h` normalization 与 game orientation。不能脱离定义说“V 越大越可捕”。
