# READING NOTE — P0025 — Task Assignment for Multiplayer Reach–Avoid Games in Convex Domains via Analytical Barriers

## 1. Paper positioning
- Problem: [原文] 在 bounded convex planar domain 中，多个 evaders 试图越过直线 target line 进入 target region；多个 pursuers 要在此之前捕获尽可能多的 evaders。论文先求 **pursuit coalition vs one evader** 的 analytical barrier/winning regions，再把 coalition capturability 变成 constrained assignment。
- Main predecessors: [原文] Isaacs barrier/game of kind；HJI reach-avoid；P0024 pairwise outcomes + maximum matching；two-pursuer reach-avoid / Apollonius geometry。
- Why this paper was needed: [原文] P0024 的 maximum matching 只从 1v1 outcomes 引入 cooperation，不能表示“任何单个 pursuer 都失败，但两个 pursuers 合作可赢”。本论文把 cooperation 提前到 **certificate construction** 本身。
- Map role: [AI判断] R-PE-01 中与 CoCap support recruitment 最直接的理论桥：`coalition state → guaranteed capturability → feasible coalition-target edge → resource-constrained allocation`。

## 2. Problem setting
- Agents / targets: [原文] `N_p` pursuers、`N_e` evaders；bounded convex `Ω⊂R^2` 被 straight target line `T` 分为 target region `Ω_tar` 与 play region `Ω_play`。（Sec. II-A, PDF p. 3 / IEEE p.109）
- Dynamics: [原文] point-mass simple motion：`ẋ_Pi=v_Pi u_Pi`, `ẋ_Ej=v_Ej u_Ej`, `||u||_2=1`。（Eq. (1), p. 3）
- Action space: full-speed instantaneous heading；可瞬时转向。
- Information structure: [原文] Sec. II-B 采用 **nonanticipative pursuit-team information structure**：pursuit team 使用 full current state，并可响应 evasion team 当前 input；作者把其表述为 Stackelberg instantiation。（PDF p. 4 / IEEE p.110）
- Sensing: [原文] information set 包含所有 pursuers/evaders current positions；不是 local sensing。
- Communication: not explicitly constrained。
- Map / obstacles: [原文] Ω 必须 convex；target boundary 是 straight line；无内部 obstacles formulation。
- Target behavior: adversarial evader，最佳策略下争取先到 `Ω_tar`。
- Capture: [原文] **point capture**；`x_Pi=x_Ej` 且发生在 `Ω_play` 才算 capture；一旦 evader 进入 `Ω_tar`，之后不再允许 capture。（Sec. II-A, p. 3）
- Speeds: [原文] homogeneous pursuers `v_P`、homogeneous evaders `v_E`；Assumption 4 定义 `α=v_E/v_P`, 且 `0<α<1`，即 pursuers strictly faster。（p. 4）
- Termination/objective: maximize number of evaders guaranteed intercepted before target entry。

### Exact initial-deployment assumptions
- **Assumption 1 — Isolate Initial Deployment**: [原文] all pursuer positions mutually distinct、all evader positions mutually distinct、pursuer–evader positions distinct；无 initial capture。（p. 4）
- **Assumption 2 — Constrained Initial Deployment**: [原文] all pursuers initially in `Ω_play∪T`；all evaders in `Ω_play`。（p. 4）
- **Assumption 3 — Relaxed Initial Deployment**: [原文] pursuers can initially lie anywhere in `Ω`；evaders still start in `Ω_play`。（p. 4）

[原文] Sections IV-C/D first solve Assumption 2；Sec. IV-E uses **virtual pursuers** to reduce Assumption 3 to previous case。（Corollary 1, PDF p. 13 / IEEE p.119）

## 3. Core idea
### Plain-language summary
[原文] 距离不是这里的“谁该支援谁”的定义。对于 coalition `k` 和 target `E_j`，真正的问题是：以当前 coalition positions 为初态，是否存在 coalition control，使得**无论 evader 怎样控制**，都能在 evader 到 target region 前 capture？

若 yes，`E_j` 位于 coalition 的 pursuit winning region `W_P^{n_k}`，于是 coalition-target assignment edge 是 feasible。然后 assignment solver 再决定哪些 feasible coalitions 同时执行，保证不重复使用同一 pursuer。

### Coalition winning certificate
[原文] Sec. IV-A Problem 1 定义：固定 coalition initial state `X_k^0`，找 `W_P^{n_k}(X_k^0)⊂Ω_play`，使若 `E_j` 初始位于其中，则 `∃ P_k∈U^{n_k}, ∀ u_Ej∈U`，`E_j` 在进入 `Ω_tar` 前被捕。

Problem 2 定义 EWR `W_E^{n_k}`：`∃u_Ej, ∀P_k`，evader 能在不被捕下进入 target region。barrier `B^{n_k}` 分隔 PWR/EWR。（PDF p. 6 / IEEE p.112）

[AI判断] 这就是最干净的 `coalition feasibility certificate`：它不是“期望表现好”，而是 game-of-kind guarantee。

## 4. Method details
### 4.1 Single-pursuer geometric primitive
[原文] 对一名 pursuer 与一名 evader，evader 的 evasion region (ER) 是比 pursuer 更早可达的点集：

`R_e = {z | ||z-x_E^0||_2 < α ||z-x_P^0||_2}`,

boundary `A` 取等号。（Eq. (2), PDF p. 4 / IEEE p.110）

完成平方后，`A` 为 Apollonius circle：

`η(x_E,x_P)=(x_E-α^2 x_P)/(1-α^2)`,

`r(x_E,x_P)= α||x_E-x_P||/(1-α^2)`。（Eqs. (3)–(4), pp. 4–5）

[AI判断] ER/Apollonius 是“race-to-point dominance” primitive；只有结合 target line 与 optimal terminal geometry，才升级为 reach-avoid barrier/PWR。

### 4.2 Analytical barriers for coalitions
- **Theorem 1 — Barrier for One Pursuer**: [原文] under Assumptions 1,2,4，给出 one-pursuer analytical barrier（Sec. IV-C, PDF pp. 7–8 / IEEE 113–114）。
- **Theorem 2 — Barrier for Two Pursuers**: [原文] under Assumptions 1,2,4。若 only one active pursuer，则 two-pursuer barrier 退化为该单 pursuer barrier；若两者 active，则 barrier 由 five analytical pieces 拼成。（PDF p. 9 / IEEE p.115）
- **Theorem 3 — Barrier for Full-Active Pursuit Coalition**: [原文] under Assumptions 1,2,4。对 `n_k≥3` full-active coalition，barrier 可由相邻 active pursuers 对应的 base curves 拼接。（Eq. (36), PDF p.10 / IEEE p.116）
- **Theorem 4 — Barrier for General Pursuit Coalition**: [原文] under Assumptions 1,2,4。Algorithm 1 找 unique largest full-active subcoalition `X̄_k^0`；原 coalition 与该 subcoalition **拥有相同 barrier**。（PDF p.12 / IEEE p.118）
- **Corollary 1 — Relaxed Initial Deployment**: [原文] under Assumptions 1,3,4，把位于 `Ω_tar` 的 pursuers 映射为 virtual pursuers，可用 Theorem 4 的 barrier construction。（PDF p.13 / IEEE p.119）

### 4.3 Coalition degeneration — the structural result behind assignment
[原文] **Lemma 5 (Degeneration of Pursuit Coalition), Sec. V, PDF p.14 / IEEE p.120**：对任意 `n_k≥3` coalition，若它能 guarantee capture 某 `E_j`，则必存在它的一个 **2-pursuer subcoalition** 也能 guarantee capture `E_j`。

proof mechanism: Theorem 3 的 barrier 每一部分最多只与两个 pursuers 有关；即使三人关联的 base piece `F^3` 也可拆成只涉及两个 pursuers 的部分。

[原文] **Remark 4**：因此寻找 maximum matching 时，只考虑 size 1 或 size 2 的 coalitions 即可，并且在“最大化被保证拦截 evader 数”意义下仍是 **global optimal**。

[AI判断] 这是一个极强但极模型特定的结论。它不是“现实多人围捕永远两架足够”；它依赖本文 simple-motion + faster pursuers + point capture + convex straight-line-target geometry。

### 4.4 Feasible coalition-target edge
[原文] **Definition 8**：execution pursuit coalition 只有 `n_k=1` 或 `2`。（p. 14）

[原文] **Definition 9 Prior Information Vector**：
- `r_i^1(j)=1` iff single pursuer `P_i` can guarantee capture `E_j`，否则 0；
- `r_{i1,i2}^2(j)=1` iff pair `{P_i1,P_i2}` can guarantee capture `E_j`，否则 0。

所有这些 binary feasibility bits 拼成 `r∈R^{N_v}`，且论文明确称 `r` 是 maximum matching 的唯一 prior-information input。（p. 14）

其中 execution coalition-target variable count：`N_v = N_e [N_p + N_p(N_p-1)/2] = N_e N_p(N_p+1)/2`.

### 4.5 0–1 assignment problem — exact equations
[原文] **Theorem 5 (Maximum Matching), Sec. V, PDF pp.14–15 / IEEE 120–121** 在 Assumptions 1,3,4 下给出 pursuit team 能 guarantee 阻止到达 target 的 evader 数 `q`：

`q = maximize   c^T z`

subject to

`A_1 z ≤ b_1,  A_2 z ≤ b_2,  A_3 z ≤ b_3`,

`z=[s^1,s^2]^T=[z(1),...,z(N_v)]^T`, `z(i)∈{0,1}`.  (Eq. (50), p. 15)

paper 定义：
- `c = ones(N_v,1)`；
- `b_1=r^T`, `A_1=I_{N_v}`；
- `b_2=ones(N_e,1)`, `A_2=ones(1,N_v/N_e)⊗I_{N_e}`；
- `b_3=ones(N_p,1)`；`A_3` 由 Algorithm 2 编码每个 execution coalition 包含哪些 pursuers。

#### Constraint semantics
[原文]
1. `A_1z≤b_1=r^T`：只能选 certificate 为 feasible 的 coalition-target pair；
2. `A_2z≤b_2`：每个 evader 最多分配给一个 execution coalition；
3. `A_3z≤b_3`：每个 pursuer 在一次执行中最多出现在一个 coalition。

因此：
- [原文] **允许多个 pursuers 分给同一个 target**，但本文最优 execution coalition 至多 2 人；
- [原文] 同一个 target 不会同时被两个不同 coalitions 重复分配；
- [原文] 同一个 pursuer 不能同时服务两个 targets。

[原文] optimal `z*=argmax_z c^Tz`；`q` 是 unique，但最大 matching `z*` 可能不唯一。（Remark 7, p.15）

### 4.6 How strong is “global optimality”?
[原文] Remark 4 + Theorem 5 支持：在本文 assumptions/game semantics 下，只考虑 size≤2 execution coalitions 的 reduced assignment，仍能得到 **最多 guaranteed intercepted evaders** 的 global-optimal matching。

[AI判断] 其 scope 必须限定：
- optimality 是 **number of guaranteed interceptions**；
- 基于论文 analytical winning certificates；
- 不等于 arbitrary multiplayer trajectory/game 的全局 Nash/saddle solution；
- 不覆盖 local sensing、nonconvex obstacles、higher-order UAV、finite turning、uncertain model、sequential/repeated arrivals、coalitions 之间时空耦合。

[AI判断] reduced problem 仍是 0–1 integer program；论文实现显著降维，但不应把“reduced ILP”泛化成“任意规模 polynomial-time exact assignment”。

## 5. Evidence
- Simulation: [原文] `N_p=5, N_e=6`, `v_P=1`, `v_E=0.7`, `α=0.7`；展示 one/two/multi-pursuer barriers 与 maximum matching。（Sec. VI, pp.15–16）
- Computation: [原文] 31 analytical barriers in示例约 0.984 s，0–1 matching约 0.025 s；这些是单一 MATLAB/laptop setting，不是 asymptotic guarantee。（p.15）
- Key behavioral evidence: [原文] 示例存在一个 evader，任何单 pursuer 都不能 guarantee capture，但 two-pursuer pair 可以，因而 reduced coalition matching size 从 pure 1v1 的 2 提升到 3。（pp.15–16）
- Real experiment: none。

## 6. Limitations
### Author-stated [原文]
Conclusion/Future Work (PDF p.17 / IEEE p.123)：
- players 都是 simple motion、可瞬时转向；future work 要考虑 Isaacs-Dubins 等更现实 dynamics；
- extension to nonconvex domain is nontrivial；可先用 convex approximation 得 conservative result；
- distributed multiplayer RA under limited communication/computing 是 open direction。

### Evidence-visible [原文 + AI判断]
- point capture；pursuers strictly faster；homogeneous team speeds；full/current global state + nonanticipative advantage；convex domain + straight target line。
- assignment 是从某一 joint snapshot/initial configuration 得到；虽然 analytical barrier 允许快速重算，但 theorem 并未证明任意高频 switching/recruitment 下仍保持 one-shot optimality。
- coalition-to-target feasibility是 binary，无 uncertainty calibration。

## 8. Relation to CoCap
### Why `agent-target distance` is weak
[AI判断] distance 只回答“现在近不近”，而 P0025 的 feasibility 实际依赖：
- target 到 **escape/goal boundary** 的相对位置；
- pursuer/evader speed ratio；
- coalition 几何互补性；
- 是否处于 winning-region 的哪一侧；
- target strategy 的 worst-case；
- 资源冲突（某 pursuer 去支援会失去其他 assignment/coverage 能力）。

所以一个较远但能封住关键 escape direction 的 support agent 可能比最近 agent 更有价值；两个都“近”的 agents 也可能几何冗余。

### Better conceptual form for CoCap `U_ij`
[AI判断] 更合理的 target/support utility 应近似 **coalition capturability margin**，而非单纯 distance：

`C(S,j) ≈ signed/robust margin that coalition S can guarantee/likely capture target j`.

若当前 coalition 为 `S_j`，候选 support agent `i` 的 recruitment utility 可用边际增益：

`Δ_i(S_j,j) = C(S_j∪{i},j) - C(S_j,j)`

再减掉 opportunity cost（离开 coverage、失去别的 target assignment、通信/碰撞风险）。

[AI判断] P0025 给的是 binary `C∈{0,1}` oracle；CoCap 需要 learned/probabilistic/robust continuous version。

### Directly reusable
1. coalition-target feasibility as an explicit object；
2. resource exclusivity constraints（agent 不应被多个 targets 同时招募）；
3. assignment objective directly maximize feasible captured targets，而非平均最近距离。

### Needs relaxation
- full state → local/intermittent enemy observation + neighbor messages；
- known simple motion → UAV dynamics/unknown learned evader；
- deterministic binary certificate → calibrated probabilistic/robust margin；
- static/one-shot assignment → dynamic recruitment / release / post-capture return；
- convex no-obstacle → clutter/boundary-assisted capture；
- pursuer faster → equal/faster evader regimes。

### Potential CoCap implementation candidates
1. **Coalition feasibility auxiliary head**：训练 `C(S,j)` 预测 offline teacher label（先用 simplified analytical/HJI scenes，再 finetune from rollout outcomes）。
2. **Support recruitment gate**：只有 `Δ_i` 超过阈值才加入 target，阈值同时考虑 coverage opportunity cost。
3. **Assignment ablation**：distance-only `U_ij` vs pair-capturability vs coalition-marginal-capturability；评估 capture rate、support count、wasted recruitment、coverage loss。
