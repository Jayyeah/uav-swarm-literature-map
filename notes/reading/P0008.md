# READING NOTE — P0008 — Franchi, Stegagno & Oriolo 2016 — Decentralized 3-D encirclement

## 1. Paper positioning
- **Problem:** [原文] 多机器人在 3-D 中围绕移动 target 形成 regular circular/splay-state encirclement，同时可加入 guaranteed inter-robot collision avoidance。
- **Main predecessors:** planar collective circular motion、cyclic pursuit、3-D formation、earlier distributed target localization/encirclement。
- **Why this paper was needed:** [原文] 把 3-D/2-D encirclement、decentralized estimation、collision safety、UAV simulation 与 onboard-only ground-robot experiment 放入一个完整框架。
- **Genealogy role:** [AI判断] 本批最重要的 `decentralized ≠ partial observation` 证据之一。

## 2. Problem setting
- **Agents / targets:** [原文] `n` robots；单一 3-D moving target。
- **Dynamics:** [原文] theorem-level model `\dot p_i=u_i`（Eq. (1)），kinematic fully actuated point robot；复杂平台通过 differential flatness / trajectory tracking 跟随 reference。
- **Action space:** Cartesian velocity at encirclement layer；quadrotor/wheeled platforms由 low-level tracker实现。
- **Sensing / observation:** [原文] controller 需要 target frame/global quantities `(p_T,\dot p_T,R_T,\dot R_T)` 以及 phase information。Sec. 3.4 允许只 **一个 informed robot** 直接测得/被任务告知这些 global quantities，其余 robot 用 distributed estimator 重建。
- **Communication:** [原文] communication graph 可时变但始终 connected；Controller 只需 predecessor/successor phase（可 multi-hop），global quantity estimator通过邻居交换传播。
- **Centralized/decentralized:** [原文] controller/estimator decentralized；不需 central controller。
- **Map / obstacles:** 无环境障碍；有 finite-size robot collision safety。
- **Target behavior:** moving target，轨迹不按 adversarial game 选择。
- **Speed ratio:** 无 pursuit speed-ratio/no-escape条件。
- **Capture / termination definition:** encirclement = radius/phase/angular-speed/plane-height asymptotic conditions；没有 capture terminal event。
- **Important terminology:** [原文 + AI判断] Version 2 的 **escape window `s`** 是稳态时相邻 robot 穿过圆上一点的时间间隔（Sec. 2/3.2），不是 PE 中 target 的 escape gap/winning certificate。

## 3. Core idea

### Plain-language summary
[原文] 先在 target-centered cylindrical coordinates 中把 encirclement 拆成 radial、phase、height 三个子目标；再通过 local phase consensus 形成均匀环。若某些 global target/frame quantities 只有一台 robot 知道，就用 consensus tracking 传播到每台 robot。安全版本延迟 radial contraction，直到 phase separation 足够，从而避免碰撞。

### Mathematical / algorithmic mechanism
[原文] target frame 中
`q_i=(ρ_i,φ_i,z_i)^T=q(R_T^T(p_i-p_T))`（Eqs. (6)–(9)）。
通过
`u_i=\dot p_T+R_T(J_i^{-1}v_i-\dot R_T^T(p_i-p_T))`（Eq. (22)）
使 `\dot q_i=v_i`（Eq. (23)）。

基础 radial/height：
- `\dotρ_i=k_ρ(ρ*-ρ_i)` — Eq. (24)
- `\dot z_i=-k_z z_i` — Eq. (25)

Version 1 phase：
`dotφ_i=ω*+k_φ(\barφ_i-φ_i)` — Eq. (26)。

## 4. Method details

### Classical control papers
- **Controller 1:** [原文] Proposition 1：给定 `ρ*`,`ω*`，Eqs. (22),(24)–(26) 使 `ρ_i→ρ*`,`φ_i→\barφ_i`,`dotφ_i→ω*`,`z_i→0` 全局指数收敛。
- **Controller 2:** [原文] 用 desired escape window `s` 通过 `Δ_i/s` 调 angular rate（Eq. (29)）；Proposition 2 全局指数收敛。
- **Controller 3:** [原文] distributed angular-speed consensus（Eqs. (30)–(31)）；Proposition 3 收敛到 forcing-term average。
- **Global-quantity estimator:** [原文] Sec. 3.4 Eq. (34)，只有 informed robot `l` 知道 generic global scalar `η`；其余 robot 用 neighbor estimate/derivative average。Proposition 4：communication graph 始终 connected ⇒ 每台 `\hatη_i` 全局收敛到 `η`。
- **Estimator caveat:** [原文] 成功依赖 estimation dynamics 与 controller dynamics 的足够 time-scale separation；作者明确说对快速 UAV 可能更 critical。
- **Communication/scalability:** [原文] Sec. 3.5：graph 最少可退化为 tree；predecessor/successor phase 可 multi-hop；per-robot message rate O(1)，network total O(n)；`n` 本身可未知。
- **Collision-safe controller:** [原文] Proposition 8 将 radial law 改为 Eq. (43) `dotρ_i=λ(ρ_i,σ)kρ(ρ*-ρ_i)`，在给定初始 radial separation 与最小 encirclement radius 条件下保证 no collision + encirclement convergence。Proposition 9 再用 decentralized `\hatσ_i` 保留该 guarantee。
- **Guarantee type:** formation convergence + collision safety；不是 target capture/no-escape。

## 5. Evidence
- **Simulation — 3-D point robots:** [原文] moving target / rotating encirclement plane；global `(p_T,\dot p_T,R_T,\dot R_T)` 均由 Eq. (34) 分布式估计，并刻意设为仅 1 robot informed。
- **Simulation — quadrotor UAVs:** [原文] Sec. 5.2 使用 SwarmSimX/TeleKyb rigid-body quadrotor；encirclement controller生成 reference，built-in Cartesian+attitude tracking controller执行。是 UAV simulation，非 hardware。
- **Physical experiment:** [原文] Sec. 5.3，Khepera III differential-drive robots。每台装 Hokuyo URG-04LX，FOV 240°、后方 120° blind zone，并有 Wi-Fi。
- **Raw sensing & reconstruction:** [原文] robot 从 laser scan 提取视野内其他 robot 的匿名 relative positions，并把这些 measurement + odometry **broadcast**；每台执行 mutual localization，得到其收到数据所覆盖的所有 robot 的 relative position，包括自身 blind zone 内 agent，并可识别 target。作者强调无需 external tracking。
- **Dynamic team-size experiment:** [原文] 3-agent triangle → 加第4台形成 square → kidnap/release 后恢复 → remove 后回 triangle → 再 remove 成 dipole（Figs. 9–10）。
- **Moving-target hardware:** [原文] 第二个 Khepera experiment 用 3 encirclers 围绕沿直线移动 target。
- **Real UAV:** [原文] 无；conclusion把 quadrotor experimental validation 列为 future work。

## 6. Limitations

### Author-stated [原文]
- distributed estimator依赖 time-scale separation；
- quadrotor real experiment 尚待未来工作；
- safety controller的 sufficient conditions对 `ρ*`、initial radii/separation 有要求。

### Evidence-visible [原文 + AI判断]
- `decentralized` 的 raw information 并不等于只用局部不完整 target state：theory中最终每 robot 都估计所需 global target/frame quantities；hardware更通过 broadcast + mutual localization 重建 blind-zone agent/target 相对状态。
- graph 要持续 connected；phase info可 multi-hop。
- 无 environmental obstacles；无 target loss/reacquisition logic。
- add/remove robot 是 externally induced cardinality change，非 target-wise role allocation 或 capture-triggered coalition release。

### Our inference [AI判断]
- 这篇论文最直接证明：**decentralized computation can still yield effectively global information at each agent**。
- 其 hardware laser 有真实 FOV/blind zone，但 blind zone 被 team-wide data fusion 填补；因此不能作为“严格 local enemy knowledge”前例。
- `escape window` 不可用于支持“no-escape capture”叙事。

## 7. Literature lineage
- **Important predecessors:** planar splay-state/encirclement、relative-bearing/cyclic-pursuit、early distributed localization。
- **Same-era alternatives:** centralized global-vision encirclement等。
- **Later citations/extensions:** 本批不搜索；P0010 将 distributed computation推进到 aggregative feedback optimization，P0012 将 perception推进到 noisy range + interception。

## 8. Relation to CoCap
- **Closest similarities:** moving target、decentralized execution、communication topology、collision safety、部分 onboard sensing。
- **Fundamental differences:** 单目标；global target/frame quantities最终被 estimator reconstruction；无 coverage/search、target-wise subgroup、capture event、release。
- **Does it cover a candidate novelty?** [AI判断] 覆盖“decentralized 3-D encirclement + collision avoidance + onboard-only ground-robot sensing”；不覆盖 strict/intermittent target knowledge 或 capture lifecycle。
- **Directly reusable ideas:** distributed global-quantity estimator作 classical baseline；phase/radius/height error decomposition；collision-safe radial gating；team-size robustness test。
- **Non-transferable assumptions:** connected graph、one informed robot/global target-frame quantity source、time-scale separation、single target。
- **New research questions exposed:** CoCap 若使用邻居传播，必须明确传播后是“local belief”还是已经近似 global reconstruction；否则 novelty wording 会被 P0008 反证。
