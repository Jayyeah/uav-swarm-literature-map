# READING NOTE — P0004 — Lan, Yan & Lin 2010 — Reachability/invariance target enclosing

## 1. Paper positioning
- **Problem:** [原文] 让多台受非完整约束的 unicycle 围绕固定目标形成半径 `R` 的均匀圆周运动，并在有限 sensing 条件下保证 near-target 阶段的可见性不丢失。
- **Main predecessors:** [原文] cyclic pursuit、collective circular motion、早期 target-capturing 与 unicycle enclosing 工作。
- **Why this paper was needed:** [原文] 早期方案常要求预先标号/固定 topology、全局 centroid 或只给局部稳定性；本文用 reachability + invariance 构造 hybrid law，给出更强的 attraction/global reasoning。
- **Genealogy role:** [AI判断] classical “finite sensing/local information” anchor；同时是一个典型例子，说明 **有限 sensing ≠ 未知目标 search**。

## 2. Problem setting
- **Agents / targets:** [原文] `n` planar unicycles；单一 **stationary** target/beacon。
- **Dynamics:** [原文] Eq. (1)
  `\dot x_i=v_i cosθ_i`, `\dot y_i=v_i sinθ_i`, `\dot θ_i=ω_i`,
  且 `|v_i|≤\bar v`, `|ω_i|≤\bar ω`。
- **Action space:** linear/angular velocity。
- **Sensing / observation:** [原文] 无绝对位置。若 vehicle `i` 能感知对象 `j`/target，只测相对 distance `d_ij`/`d_i0` 与 bearing `α_ij`/`α_i0`（Sec. 2.2, Fig. 1）。
- **Finite sensing model:** [原文] 定义 target-centered disk `D0`，半径 `2R`。在 `D0` 内，vehicle 可感知 target 及同在 `D0` 的其他 vehicles；在外部则假设它能直接或经 multi-hop sensing graph 间接连到 target/`D0` 内 vehicle。作者称若物理 sensor radius > `4R`，近区假设可满足。
- **Communication:** [原文 + AI判断] close-range controller 需要本地 target 与 pre-/next-neighbor 相对量；global argument 允许信息/感知沿 vehicle chain hopping。论文没有 unknown-target map search。
- **Centralized/decentralized:** [原文] decentralized/distributed；不使用绝对位姿。
- **Map / obstacles:** 无环境障碍。
- **Target behavior:** fixed。
- **Speed ratio:** 无 PE speed ratio；只有 robot input bounds。
- **Capture / termination definition:** [原文] uniform circular motion around target + equal angular spacing；作者也使用 “capture” 字样，但终态是 enclosing orbit，而非 target terminal capture。

## 3. Core idea

### Plain-language summary
[原文] 把问题分成两层：
1. 已经进入目标近区 `D0` 的 robot：用 hybrid reachability/invariance controller 保证不会离开 target-visible region，并最终进入一个可稳定围绕目标的 invariant set；
2. 还在 `D0` 外的 robot：沿能通到目标/近区的 sensing chain 追踪 target 或邻居，逐个被“拉入” `D0`。

[AI判断] 关键是它解决了 **“已存在到目标的 sensing path 时，如何从有限 sensing 场景进入并保持 enclosing”**；没有解决“目标未知在哪里、完全没有感知链时如何 search”。

### Mathematical / algorithmic mechanism
[原文] 通过 path-following 坐标变换，把每台 unicycle 写成相对目标圆轨道误差 `(y_e^i, θ_e^i)`：
`\dot y_e^i=v_c^i sinθ_e^i`,
`\dot θ_e^i=ω_c^i + v_c^i cosθ_e^i/(R+y_e^i)`（Eq. (2)）。

状态域 `S0` 对应 `D0\Z0`，再划分成 invariant target set `S` 与 `S1…S4`（Fig. 6）。`S` 内控制 Eq. (4) 通过 `Γ(ψ_i^-−ψ_i^+)` 调整相邻 separation angles，同时 Lyapunov term 使轨道误差归零。

## 4. Method details

### Classical control papers
- **Controller:** [原文]
  - `S` 内：Eq. (4) local enclosing law；
  - `S1/S2`：Eqs. (8)/(9) feedback-linearizing reach controllers；
  - `S3/S4`：Eqs. (10)/(11) simple directional reach controllers；
  - 按状态切换形成 hybrid controller Eq. (12)。
- **Graph/topology:** [原文] close region 中 next-/pre-neighbor 由当前几何顺序定义，topology 可随状态变化；只需 target + 两个相邻 robot 的 local measures，尽管 `D0` 内假设所有成员彼此可见。
- **Visibility/invariance:** [原文] Theorem 3.1：若 `φ_i(0)∈S`，则 `S` 正不变；所以一旦进入该稳定子域就不会因控制而离开可见近区。
- **Phase/collision property:** [原文] Theorem 3.2 维持 positive separation；Remark 3.2 说明在该 close-range result 下不会发生 vehicle-vehicle collision。
- **Convergence:** [原文] Theorem 3.3：初始均在 `S` 且无两车与目标共线时，Eq. (4) 使 `φ_i→0` 且 separation angles 全部趋于 `2π/n`。
- **Reachability:** [原文] Theorems 3.4/3.5 + Corollaries 3.1/3.2：`S1…S4` 在有限时间进入 `S` 或经过相邻分区最终进入 `S`。
- **Main near-range result:** [原文] Theorem 3.6：hybrid control (12) 对 `D0` 内几乎所有初始状态解决 cooperative target enclosing。
- **Global argument:** [原文] Sec. 4：若 `D0` 外 robot 能直接看到 target/近区 robot，或经 sensing graph 存在一条最终连到 `D0` 的 path，则可用现有 target-tracking law 形成 rooted forest，逐个把 robot 带入 `D0`。
- **Guarantee type:** reachability + positive invariance + enclosing convergence；不是 search completeness，不是 PE capture。

## 5. Evidence
- **Baselines:** 主要与前序 local enclosing/circular-motion 方法定性比较。
- **Metrics:** state errors `y_e, θ_e` 与 separation angles。
- **Simulation:** [原文] 5 unicycles，固定目标；3 台起初在 `D0`，2 台外部。外部使用现有 target-tracking controller；随着第 4/5 台加入，群体重配置成 4/5 边均匀环形（Figs. 10–15）。
- **Real experiment:** [原文] 无。
- **Scalability/generalization:** local close-range law不依赖全局 absolute position，但 global approach 依赖“存在连到 target/inside-D0 的 sensing path”。

### READ clarification relative to SCREEN
[原文 + AI判断] SCREEN 正确指出该文不是 unknown-target search。READ 进一步精确化：论文并非简单“忽略 D0 外问题”，而是在 Sec. 4 给出 rooted-forest / neighbor-tracking 的 global construction；然而它的先决条件就是每个外部 robot **直接或间接已经连到目标/近区**。若整队完全不知道目标、没有 sensing path，这个 construction 不启动。

## 6. Limitations

### Author-stated [原文]
结论明确把以下列为未来工作：更完整的 collision avoidance、moving-target tracking performance 等。

### Evidence-visible [原文 + AI判断]
- 目标固定；不处理 strategic/maneuvering target。
- “有限 sensing”仍有很强连通性假设：近区内部几乎全可见，远区必须存在通向 target/near group 的 chain。
- 没有 FOV、occlusion、measurement noise、target-loss/reacquisition。
- 全局 hybrid problem 的 hard collision guarantee 并不完整；close-range phase separation 有 no-collision 结论，但作者仍把 collision avoidance 列为 future work。
- 没有物理 experiment。

### Our inference [AI判断]
- 该文解决的是 **visibility-preserving enclosing under finite range**, 不是 **intermittent detection/search under unknown target state**。
- 对 CoCap 的 novelty 边界：不能宣称“classical encirclement 都要求无限/全局 target sensing”；但仍可强调 CoCap 若真正允许 target 未发现、丢失及不确定 belief，则问题更强。

## 8. Relation to CoCap
- **Closest similarities:** finite sensing、local relative geometry、state-dependent interaction、agent 可从“far”转入“coordinated near”。
- **Fundamental differences:** 单一固定 target；没有 unknown search、multi-target、dynamic coalition、capture terminal event、coverage role。
- **Does it cover a candidate novelty?** [AI判断] 覆盖“finite-range local-information enclosing”的基础 claim；不覆盖 intermittent discovery + uncertainty + coalition lifecycle。
- **Directly reusable ideas:** visibility-invariant set；far/near hybrid gate；用 reachability/invariance 做 task-phase safety certificate。
- **Non-transferable assumptions:** fixed target、sensing-rooted forest、close-region strong visibility。
- **New research questions exposed:** 在 target sensing graph 可断、目标移动、不同 agent 只间歇发现 target 时，如何把 “进入可见集/保持可见” 变成 belief-aware learned gate。
