# READING NOTE — P0028 — Cooperative Pursuit With Multi-Pursuer and One Faster Free-Moving Evader

## 1. Paper positioning
- Problem: [原文] 多个较慢 pursuers 对一个 **faster free-moving evader**；evader 的运动方向/逃逸策略不受预设限制。目标不是仅形成 ring，而是给出 distributed encirclement + inward hunting，并导出 sufficient conditions 保证最终 nonzero-radius capture。
- Main predecessors: [原文] faster-evader games常通过限制 evader direction/region 或要求 angle-even encirclement 才能得到结果；作者自己的 earlier work [30] 引入 overlapping-angle 思路；其他工作研究 “perfectly encircled” 特殊结构与 parallel guidance。
- Why this paper was needed: [原文] 较慢 pursuer 对 faster evader 的 point capture generally impossible；有 nonzero capture radius 时，多 pursuers 需要同时解决“封住所有逃逸方向”和“向内逼近”，二者存在 control tradeoff。
- Map role: [AI判断] 本批从 **encirclement geometry → actual guaranteed capture** 的关键 bridge；它直接说明“看起来围成环”为什么还不是 capture certificate。

## 2. Problem setting
- Agents / targets: [原文] one faster free-moving evader + `n` pursuers。
- Pursuer dynamics: [原文] single-integrator `ṗ_i=v_i`, `||v_i||_2≤V_i`。（Eq. (1), PDF p.2 / IEEE p.1406）
- Evader dynamics/model: [原文] 不假定 evader 的 kinematic model 或 escape policy；只使用其 position，强调 direction/strategy unknown。（Remark 1, p.2）
- Speed ratio: [原文] `λ_i=V_i/V_e<1`，pursuer i 比 evader 慢。（Eq. (2) vicinity, p.3）
- Capture radius: [原文] **nonzero** `d_c>0`；若某 pursuer 与 evader 距离 `≤d_c`，capture。（Definition 1, p.4）
- Sensing / observation: [原文] Assumption 1：每个 pursuer 能获得 evader、自身、以及角度排序下两个 nearest neighbors 的 position information。（p.4）
- Communication: distributed neighbor use；但 [AI判断] 每个 pursuer 始终有 evader position，仍强于 CoCap 的 local/intermittent target sensing。
- Map / obstacles: no environmental obstacles in core theorem；后续只加 pursuer-pursuer distance maintenance/intercollision avoidance。
- Termination: 存在 `t_c>0` 和至少一个 pursuer i，使 `||p_i(t_c)-p_e(t_c)||≤d_c`。（Problem Description, p.4）
- Solution object: sufficient capture conditions + distributed velocity law；不是 HJI winning-region computation。

## 3. Core idea
### Plain-language summary
[原文] 每名较慢 pursuer 只能“封住” evader 一部分 possible headings。多人 capture 的第一步是让所有 heading sectors 的 union 覆盖完整 `2π`，即没有 escapable angular gap；第二步还要让 pursuers 保持这种 no-gap enclosure 的同时持续向内减小半径。只做第一步可能永远围着不抓到，只做第二步可能打开 gap 让 faster evader 逃掉。

[AI判断] 因此：`ring/surrounding ≠ no-escape certificate ≠ capture`。

更接近论文逻辑的链是：`speed-aware occupied-angle coverage → no escapable direction → enclosure invariant/maintenance → positive inward component → enter capture radius`。

## 4. Method details
### 4.1 One pursuer’s occupied angle from Apollonius geometry
[原文] 在 evader-centered local frame，若 pursuer i 与 evader 分别以最大速度沿固定方向运动，meeting point 满足 Apollonius relation（Eqs. (2)–(3), p.3）。从 evader 到 Apollonius circle 的两条 tangent lines 之间角度定义为 occupied angle `θ_i`。

几何关系：`sin(θ_i/2)=λ_i` (Eq. (4))，所以 `θ_i = 2 sin^{-1}(λ_i)` (Eq. (5), p.3).

[原文] `θ_i/(2π)` 表示 pursuer i 能占据/拦截的 free-moving direction fraction。

[AI判断] 这个 angle 是 **speed-aware interception heading sector**，不是普通“pursuer 在 evader 周围占了多少中心角”。

### 4.2 Escapable angle and group occupied angle
令 pursuers 按 evader-centered polar angle `α_i` 排序。相邻 i,i+1 的 coverage angle（Eqs. (8a,b), p.3）：

`ε_{i,i+1}=α_{i+1}-α_i-(θ_{i+1}+θ_i)/2`

（末首 pair 需加 `2π`）。

- [原文] `ε≤0`：overlapping occupied angle；
- [原文] `ε>0`：escapable angle，即两个相邻 pursuers 都不能占据的 heading gap。

Group occupied angle：

`θ_G = Σ_i θ_i + Σ_{ε_{i,i+1}≤0} ε_{i,i+1}` (Eq. (9), p.3)，`θ_E=2π-θ_G` 为总 escapable angle。

paper 定义 geometry “success rate” `P=θ_G/(2π)`（Eq. (11)）。

[AI判断] `P` 是 heading-coverage fraction，不是统计意义 capture probability；CoCap 不应直接把它解释成概率。

### “总 occupied angle = 2π”到底意味着什么？
[原文] `θ_G=2π` 表示所有 free-moving directions 均被 group occupied，即不存在 positive escapable gap；paper 说 evader 被 trap/kept in union of pursuers' capture domains。（Sec. II-B / Theorem 1 proof）

[AI判断] 它的关键语义是 **no instantaneous escape heading remains under this interception geometry**。它不是“pursuers 形成一个任意闭合 polygon/ring”这一纯拓扑陈述。

### 4.3 How many pursuers are needed?
[原文] homogeneous occupied angle `θ` 时 Eq. (10)：

`n_min = [2π - Σ_{ε≤0} ε]/θ > 2π/θ`.

因此至少要使总 speed-derived angular capability 足够覆盖 `2π`；overlap 会浪费 coverage。

[AI判断] `n>2π/θ` 是直观 lower-bound-style condition，不应脱离当前 geometry 当成唯一 minimum-count closed form。

### 4.4 Encirclement controller
[原文] 每个 pursuer 有 tangential surrounding direction 与 radial hunting direction。（Fig.3, p.4）

encirclement dynamics：`α̇_i = k_i(ε_{i,i+1}-ε_{i-1,i})`, `k_i>0` (Eq. (12), p.4).

**Theorem 1, Sec. III, PDF pp.4–5 / IEEE 1408–1409**：在以 static evader position 为中心的 local polar formulation 中，如果 `2π - Σ_i θ_i ≤ 0` (Eq. (13))，则 Eq. (12) 使 coverage angles 达到 consensus，最终每个 `ε_{i,i+1}≤0`，从而 `θ_G→2π`，并保持 no-gap enclosure。（Eqs. (21)–(23)）

[AI判断] 这是 **encirclement/no-gap** theorem，不应单独引用为一般 moving faster evader 的最终 capture theorem；真正 free-moving capture guarantee 在 Theorem 2。

### 4.5 Why inward/radial hunting is necessary
[原文] radial hunting law：`ṙ_i=-h_i r_i`, `h_i>0` (Eq. (25), p.5)，对应 hunting velocity Eq. (26)，总 velocity Eq. (27) = surrounding component + hunting component。

tradeoff 用 `β_i∈[0,π/2]` 分配 speed：`||v_is||=V_i sin β_i`, `||v_ih||=V_i cos β_i` (Eqs. (28)–(29)).

作者设计 Eq. (33) 的 `β_i`，并在 Remark 3 强调 choice flexible；更关键的是即使 surrounding need 最大，`β_i<π/2`，所以 **hunting component 始终非零**。（Sec. IV-B, p.6）

[AI判断] 这直接回答“为什么 ring 不等于 capture”：纯 tangential control 可以让 angle gap 消失，但不保证 `r_i→d_c`；必须持续消耗 radial distance。

### 4.6 Moving faster evader: sufficient capture theorem
Sec. V 引入 n-pursuer polygon、polygon-maintenance set `S_i`、neighbor set `Ω_i` 与 distance-maintenance/intercollision potentials。

[原文] Lemma 2（PDF p.6 / IEEE p.1410）指出：如果 faster evader 位于 n-pursuer polygon 内，且任意 polygon edge length `d_{i,j} ≤ 2 d_c λ_min`，则相应 coverage angles 非正，进而 `θ_G=2π`。其中 `λ_min=min_i λ_i`。

[原文] distance-maintenance set Eq. (38) 以 `R_f=2d_cλ_min` 为最大边长阈值；Eqs. (39)–(48) 用 barrier-like potential 维护 polygon edges 与 intercollision safety，并把 total velocity normalize 到 `V_i`。

**Theorem 2, Sec. V, PDF p.7 / IEEE p.1411**：若 faster free-moving evader 在 `t_0` 时位于 n-pursuer polygon 内，采用 velocity law (46)，且满足：

1. `||p_i(t_0)-p_j(t_0)||_2 < R_f`, 对所有 `p_j∈S_i`；
2. `R_o < ||p_i(t_0)-p_j(t_0)||_2`, 对所有 `p_j∈Ω_i`；
3. `R_o < R_b < R_c < R_f ≤ 2 d_c λ_min`；
4. `{p_{i-1},p_{i+1}} ⊆ S_i ⊆ Ω_i`；

则 pursuers 保持 edge upper bound 与 intercollision lower bound，`θ_G=2π` 对 `t>t_0` 保持，faster evader 被困在 no-escape capture geometry 中，并且**最终被 capture，无论 evader 采用什么 strategy**。（Theorem 2 proof, p.7）

### 4.7 Cardinality / radius / speed relation
[原文] 对 convex polygon，若任意 side `≤2d_cλ_min`，circumcircle radius 不超过 `d_cλ_min/sin(π/n)`。若希望形成 circumradius `R_p>d_c` 的 convex polygon，Eq. (49)：

`d_c λ_min / sin(π/n) > R_p`

推出 `n > π / arcsin(d_c λ_min / R_p)`.

[AI判断] 这是 capture radius、slow-pursuer speed ratio 与 required cardinality 的直接桥：`d_c` 越大或 `λ_min` 越高，同一 enclosure scale 下所需 pursuers 可减少；`R_p` 越大则需要更多 pursuers。

## 5. Evidence
- Simulation without distance maintenance: [原文] 3 pursuers, `λ=0.9` 时可以先补 gap 后 hunting capture；`λ=0.8` 时 `θ_i≈0.59π<2π/3`，三人无法让所有 `ε<0`，始终存在 escape gap。（Sec. VI-A, PDF p.8 / IEEE p.1412）
- Simulation with maintenance: [原文] 12 pursuers, `λ=0.95`, `d_c=3.1`, `R_f=5.7<2d_cλ_i`；Theorem 2 conditions 满足，`θ_G=2π` 全程保持并最终 capture。（pp.8–9）
- Real experiment: [原文] ground robots + external camera localization + ZigBee；evader 手动控制，验证算法可运行。（Sec. VII, p.9）
- Important caveat: [原文] 实验中 evader 转弯会减速，pursuers 因而得到额外 capture opportunity。（p.9）
- [AI判断] 因此实验不是对“理想 faster free-moving evader 始终保持最大速度”的 theorem worst-case 的完全物理验证。

## 6. Limitations
### Author/evidence-visible [原文]
- core theorem 无环境 obstacles；
- pursuer dynamics 为 single-integrator velocity control；真实 ground robots dynamics 更复杂，作者把 control law 视为 cooperative path planning；
- 每个 pursuer 需要 evader position 与 neighbors position；
- guarantee 是 sufficient conditions，不声称 necessary。

### Our inference [AI判断]
- “evader inside polygon + all critical edges短 enough” 是强初始几何条件；从任意散乱初态 **安全地达到** Theorem 2 invariant set，本身仍是另一问题。
- `θ_G=2π` 的构造依赖 speed bound 与准确 relative geometry；噪声/遮挡会造成 false closure。
- 3D UAV 中“角度绕一圈”需升级为 solid-angle / enclosing surface 或其他 no-escape geometry，不能直接用 planar `2π`。

## 8. Relation to CoCap
- Closest similarities: CoCap 的 encirclement reward、support recruitment、需要多人封 escape gaps、最终还需稳定 capture 而非仅 ring。
- Fundamental differences: P0028 single target、全体 pursuers知道 target position、2D single-integrator、无 clutter；CoCap multi-target/local sensing/UAV dynamics/coverage coexistence。
- Does it cover a candidate novelty?: [AI判断] 它已覆盖“多 pursuer 通过环绕 + inward approach 捕获 faster target”的基本机制，因此 CoCap 不能把“encirclement + radial closing”本身当 novelty。
- Directly reusable ideas:
  1. **occupied-angle / escapable-angle features** 比纯 angular uniformity 更有物理意义，因为显式含 speed ratio；
  2. `θ_E=2π-θ_G` 可作为 “escape-gap margin” evaluation/reward feature；
  3. support count threshold 应与 speed ratio + capture radius + enclosure scale 联系，而不是固定人数。
- Needs relaxation: local/intermittent target sensing；dynamic coalition join/leave；obstacles/boundary；higher-order UAV；multi-target conflicts；3D geometry；uncertain speed bounds。

### Potential CoCap implementation candidates
1. Observation/reward feature：对每个 target 估计最大 escape gap `max ε_+` 或 normalized group occupied fraction `θ_G/2π`，但不要称 probability。
2. Support recruitment：只有当前 coalition 的 predicted no-escape margin 不够时招募；一旦 margin 足够，更多 agents 的收益递减，让剩余 agents 继续 coverage。
3. Evaluation：将“形成 ring”拆成 `no-gap achieved`、`no-gap maintained duration`、`radial contraction`、`capture` 四个指标，诊断 3+ ring 为什么不能转成 capture。
