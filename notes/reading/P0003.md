# READING NOTE — P0003 — Kim & Sugie 2007 — Cyclic-pursuit target-capturing

## 1. Paper positioning
- **Problem:** [原文] 让 `n` 个三维全驱动点质量 agent 围绕一个目标形成等角间隔、指定半径与指定高度角的旋转/包围几何，并避免 agent-agent 碰撞。
- **Main predecessors:** [原文] Kobayashi et al. (2006) 的目标捕获/圆形包围；Marshall et al. 的 cyclic pursuit formation；Lin et al. 的 cyclic-pursuit/star-formation 分析。
- **Why this paper was needed:** [原文] 作者希望把 target-centered enclosing 做到更少信息、更少通信，并扩展到 3-D；每个 agent 只测目标与一个 cyclic successor。
- **Genealogy role:** [AI判断] 这是 classical encirclement 中重要的 terminology/genealogy anchor；标题中的 `target-capturing` 不能按现代 PE 的“强制捕获”语义读取。

## 2. Problem setting
- **Agents / targets:** [原文] `n` agents，单一可自由移动目标。
- **Dynamics:** [原文] 一阶点质量模型 `\dot p_i=u_i`（Eq. (1), Sec. 2）；论文明确说明“不考虑 agent dynamics”且假设 full actuation。
- **Action space:** [原文] 三维 Cartesian velocity input `u_i∈R^3`。
- **Sensing / observation:** [原文] agent `i` 测量
  - `r_i=p_i-p_o`：自身相对目标向量；
  - `a_i=p_i-p_{i+1}`：自身相对 cyclic prey/successor 向量；
  见 Eq. (2), Sec. 2。
- **Communication:** [原文] 无需 inter-agent communication；所需关系量由本体传感器获得。
- **Centralized/decentralized:** [原文] 分布式、memoryless；每个 agent 仅由当前目标与一个 prey 的相对量决定动作。
- **Map / obstacles:** [原文] 无环境障碍/边界；只讨论 agent-agent collision。
- **Target behavior:** [原文] `p_o(t)` 是外生的自由移动目标轨迹；没有 strategic/adversarial policy。
- **Speed ratio:** [原文] 无 pursuer/target speed-ratio game 条件；模型也没有 agent input bound。
- **Capture / termination definition:** [原文] “target-capturing”被定义成 A1–A3：目标位于均匀环绕几何中心、agent 距离收敛至 `R`、高度角收敛至 `Φ`。没有 capture radius、接触、interception、winning region 或 no-escape condition。

## 3. Core idea

### Plain-language summary
[原文] 每个 agent 追随一个固定 cyclic successor，同时把自己调到目标中心坐标系中的指定半径和高度。局部 cyclic phase update 最终把所有角间隔均匀化。

[AI判断] 这里的“capture”本质是 **target-centered regular enclosing/tracking formation**：目标仍可移动，agent 持续跟随并保持圈形，而不是把目标逼入一个终止 capture set。

### Mathematical / algorithmic mechanism
设目标中心坐标下 agent 的极/球坐标量为 `(r_i, θ_i, α_i)`，相邻 phase gap 为 `δθ_i=θ_{i+1}-θ_i`（末尾 modulo `2π`）。核心局部律（Sec. 3）：
- `\dot θ_i = k_1 δθ_i` — Eq. (5)
- `\dot r_i = k_2(R-r_i)` — Eq. (6)
- `\dot α_i = k_3(Φ-α_i)` — Eq. (7)

[原文] phase dynamics写成 circulant system `\dot θ=Aθ+B`（Eq. (9)–(10)）。除一个零特征值外其余特征值严格在左半平面，结合总 angular-rate invariant 得到 `δθ_i→2π/n`。

[原文] 真正 Cartesian input 需要把 target-frame dynamics 映射回世界系：
`u_i = \dot r_i + \dot p_o`（Eq. (21), Sec. 3）。
作者明确指出：若要求对目标运动“无误差”地维持目标捕获，目标速度 `\dot p_o` 不可避免；随后仿真专门测试 `\dot p_o` 完全不可用时的性能。

## 4. Method details

### Classical control papers
- **Controller:** Eqs. (5)–(7) 的 cyclic phase / radius / altitude 三个 decoupled local laws，再由 Eq. (21) 转成世界系速度。
- **Graph/topology:** [原文] 固定 directed cycle；agent `i` 只依赖 `i+1 (mod n)` 与目标。
- **Stability / convergence conditions:** [原文] Theorem 1 要求初始为 counterclockwise star formation：`d_i(0)>0`、`0<δθ_i(0)<2π` 且 gap 总和为 `2π`。结论：
  1. `δθ_i→2π/n`;
  2. `r_i→R`;
  3. `α_i→Φ`;
  4. clockwise/counterclockwise ordering 保持；
  5. 过程中无 agent-agent collision。
- **Guarantee type:** [AI判断] global formation convergence + collision avoidance；不是 no-escape/capture guarantee。
- **Moving target caveat:** [原文] 对一般移动目标，精确世界系执行要补偿 `\dot p_o`；未知 `\dot p_o` 的结果是 simulation evidence，不是对任意目标策略的 theorem。

## 5. Evidence
- **Baselines:** [原文] 不是现代 benchmark-style baseline；主要与前序 cyclic-pursuit/gradient enclosing 在信息需求上定性比较。
- **Metrics:** [原文] phase gap、三维/二维轨迹、目标中心 formation。
- **Ablations:** 无。
- **Simulation:** [原文] Case 1：9 agents 对 piecewise-moving target；即使令控制中的 `\dot p_o=0`，仍观察到 formation/tracking。Case 2：人为让 **prey/successor agent** 在若干时间段不可见，并 hold last `δθ_i` measurement；仍恢复 formation。
- **Real experiment:** [原文] 无。
- **Scalability/generalization:** [原文] 每 agent 固定只需一个邻居+目标；理论可任意 `n`，但依赖固定 cyclic ordering/star condition。

### SCREEN REFINEMENT
[原文 + AI判断] SCREEN 将其正确归为“目标相对量持续可用、无 CoCap 式 intermittent enemy detection”。READ 补充一个容易误读的细节：Sec. 4.2 确实模拟了 **邻居/prey 暂时不可见**，但并不是目标不可见；目标相对量仍是控制结构的一部分，也没有 search/reacquisition/belief model。因此这不改变原有 local-enemy-sensing 判断。

## 6. Limitations

### Author-stated [原文]
- agent dynamics 未建模且 full actuation；
- exact target tracking 需要目标速度；作者用仿真检验完全未知速度时的鲁棒性。

### Evidence-visible [原文 + AI判断]
- 所有 agent 在任务语义上都直接拥有目标相对位置；没有 finite range/FOV/occlusion 的目标感知模型。
- 目标是外生轨迹，不是会根据 pursuer 行为选择 escape action 的 strategic evader。
- collision guarantee 限于 agent-agent，并无障碍/边界。
- 没有 task completion，formation 是持续维持的。

### Our inference [AI判断]
- “target-capturing”是 lexical false friend：它至多说明几何 enclosure + tracking，不说明 no-escape 或 physical capture。
- 该方法对 CoCap 的主要价值是**术语边界和极简 local geometric controller genealogy**，而不是 lifecycle 或 adversarial capture baseline。

## 8. Relation to CoCap
- **Closest similarities:** target-centered multi-agent surround；distributed execution；local relative geometry。
- **Fundamental differences:** CoCap 关注 discovery/coverage/capture lifecycle；P0003 中目标对所有 agent 持续可测、单目标、固定全队、无 search/assignment/release。
- **Does it cover a candidate novelty?** [AI判断] 它杀死“无通信、只依赖局部相对几何就能围目标”这种宽泛 claim，但不覆盖 intermittent local enemy knowledge、dynamic coalition、capture-to-coverage。
- **Directly reusable ideas:** phase-gap/angle-spacing diagnostics；simple cyclic topology baseline；formation-convergence sanity check。
- **Non-transferable assumptions:** full actuation、直接目标测量、固定 cyclic ordering、无 obstacles。
- **New research questions exposed:** 如何把 cyclic/local geometry 与显式 target visibility/belief、capture feasibility 和动态 subgroup 结合，而不把“distributed”误写为“partial observation”。
