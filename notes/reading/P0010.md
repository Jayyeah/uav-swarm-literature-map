# READING NOTE — P0010 — Pichierri et al. 2026 — Triggered distributed monitoring + encirclement

## 1. Paper positioning
- **Problem:** [原文] heterogeneous ground/aerial robot team 在一个 **given static target** 周围协作 encircle，同时监测固定 points of interest，并避开危险区域；通过 event-triggered distributed aggregative feedback optimization 实现。
- **Main predecessors:** distributed/aggregative optimization、feedback optimization、event-triggered communication、coverage/encirclement/control-barrier literature。
- **Why this paper was needed:** [原文] 传统 encirclement 常是单一 formation objective；作者希望在真实 dynamics 下处理 encirclement + monitoring + safe placement 的 multiobjective tradeoff，同时避免 continuous communication。
- **Genealogy role:** [AI判断] 本批 lifecycle/persistence 最关键的 boundary paper。它证明 non-RL classical/optimization 可以 **concurrently** 结合 encirclement 与持续 monitoring objective，但并没有 `capture → release → return-to-coverage` 状态机。

## 2. Problem setting
- **Agents / targets:** [原文] `N` heterogeneous robots；一个共同 **static target** `b∈R²`；另有固定 points of interest 与 danger density。
- **Dynamics:** [原文] generic stabilized dynamics `dot x_i=r_i(x_i,u_i)`（Eq. (1), Assumption 2.2）；Sec. IV-B具体实现 quadrotor dynamics Eq. (19) + geometric low-level controller，以及 ground unicycle Eq. (21) + pose-following controller。
- **Action space:** high-level optimization variable/setpoint `u_i`; low-level quadrotor thrust/angular rates或 ground linear/angular velocity。
- **Sensing / observation:** [原文] optimization architecture中每 robot 可访问本地 state/cost/gradient 与 local estimate of aggregate。**Target location `b` 是 cost definition 的已知固定参数**；没有 target detector/target-sensing model。
- **Communication:** [原文] strongly connected, weight-balanced directed graph (Assumption 2.1)；event-triggered邻居交换两个 `d`-dimensional aggregate-tracking quantities，Eq. (11)–(12)。
- **Centralized/decentralized:** [原文] algorithmically distributed；每 robot只有 local cost/rule并通过 consensus-like trackers重建 aggregate/global gradient quantities。
- **Map / obstacles:** [原文] dangerous zones通过 local potential/density cost；inter-robot collision由 CBF safe-controller blocks处理。
- **Target behavior:** static, known。
- **Speed ratio:** 不适用。
- **Capture / termination definition:** **无 capture**。成功是对 nonconvex optimization 的 stationary/local-minimum configuration convergence。
- **Patrol/monitoring semantics:** [原文] O2 `multispot monitoring` 实际通过 `ℓ_i^spot=||p_i-s_ℓ||²`（Eq. (18)）让指定 robot 靠近固定 sensitive spot。它是持续 point monitoring/placement，不是 sweep coverage/search trajectory。

## 3. Core idea

### Plain-language summary
[原文] 把全队任务写成一个共享的 nonconvex cost：全局项要求全队角度分散、围住 target；本地项要求某些 robot 靠近各自 sensitive spots；另一项远离 dangerous areas。每台 robot 不拿到 centralized global objective state，而是通过邻居的 event-triggered messages 在线跟踪 aggregate，然后做 feedback gradient descent。

[AI判断] 这不是“先 patrol，发现 target 后切 encircle，再捕获后回 patrol”。目标从一开始就已知且永远存在，三个 objective 同时作用；没有 encounter、completion、release、reassignment 事件。

### Mathematical / algorithmic mechanism
总 local cost（Eq. (14), Sec. IV-A）：
`ℓ_i(x_i,σ(x)) = γ_1ℓ_i^coop(σ(x)) + γ_2ℓ_i^spot(x_i) + γ_3ℓ_i^danger(x_i)`。

**Encirclement:** 以 target `b` 为极坐标原点，定义 angular aggregate
`σ(x)=(N^{-1}Σ cosθ_i, N^{-1}Σ sinθ_i)^T`（Eq. (16)），
并最小化 circular concentration
`ℓ_i^coop=||σ(x)||²`（Eq. (17)）。

**Monitoring:** `ℓ_i^spot=||p_i-s_ℓ||²`（Eq. (18)）。

**Distributed tracker:** Eq. (6)/(11) 用 auxiliary `w_i,z_i` 估计不可直接获得的 `σ(x)` 与 aggregate gradient；event trigger Eq. (12) 在 local stale-data error 超过 `λ||d_i||+|ξ_i|` 时发送更新。

## 4. Method details

### Classical control papers
- **Controller/optimizer:** triggered aggregative tracking feedback, Algorithm 1 / Eqs. (11a)–(11e)。
- **Graph/topology:** strongly connected, weight-balanced directed graph。
- **Information flow:** [原文] 每 robot交换 `\hat w_i+\hatφ_i` 与 `\hat z_i+\widehat{∇_2ℓ_i}` 给 neighbors；local trackers逼近 macroscopic/global aggregate quantities。
- **Convergence:** [原文] Theorem 3.1：在 Assumptions 2.1–2.3、足够小 `α_1,α_2,λ` 和足够大 `ν` 下，trajectories bounded 且收敛到 stationary set `X`；isolated stationary local minimum 局部渐近稳定；event-trigger scheme无 Zeno。
- **Guarantee strength:** [AI判断] 是 first-order optimality/stationary-point guarantee，非 global optimal encirclement theorem，也非 capture guarantee。
- **Safety:** [原文] Sec. IV-B，CBF safe controllers分别用于 quadrotor/ground robots的 inter-robot collision avoidance。

## 5. Evidence
- **Virtual experiments:** [原文] Webots + ROS 2，分别测试纯 encirclement、encirclement+monitoring、+danger、heterogeneous team；Monte Carlo分析 communication load/scalability。
- **Monitoring assignment:** [原文] Scenario 2 中 5 points of interest **randomly assigned to five robots**；任务权重优先 encirclement。不是 runtime detection-driven role allocation。
- **Real experiment:** [原文] Sec. VI，`N=7`：3 Crazyflie + 4 TurtleBot；共同围绕 static target（duck）且监测 4 sensitive points。
- **Offboard/localization stack:** [原文] 虽通信逻辑按 robot node fully distributed 实现，但因 resource limitations，**各 robot 的 communication-protocol nodes hosted on a single workstation**；所有实验 containerized on Ubuntu workstation；robot pose由 **Vicon MoCap** 提供，另一个 workstation运行 Vicon Tracker。
- **Actuation:** [原文] Crazyflie angular-rate setpoints经 radio；TurtleBot via ROS2 WiFi。
- **Real UAV:** [原文] 有真实 Crazyflie aerial robots，但不是 fully onboard autonomous/localized stack。

## 6. Limitations

### Author-stated [原文]
- Theorem 的 parameter bounds存在但显式计算可能保守，实践中需经验 tuning。
- event-trigger/distributed architecture是主要贡献；任务模型强调 stationary optimization。

### Evidence-visible [原文 + AI判断]
- 目标 `b` 从一开始已知且固定；不存在 target detection/arrival/loss。
- O2 是固定点 monitoring placement，不是 area coverage/search。
- 所有 robot 都参与 global encirclement aggregate objective；不是“独立 patrol subgroup + capture subgroup”的动态分工。
- sensitive spots 在实验中预先分配；无 dynamic subgroup formation/recruitment。
- 没有 completion/capture event，所以没有 post-task release。
- physical stack使用 global Vicon pose与集中工作站承载 distributed nodes。

### Our inference [AI判断]
- **monitoring/patrol + encirclement ≠ post-capture recovery**。这篇论文杀死 broad claim “classical methods cannot keep other monitoring objectives active while encircling”，但对 CoCap 最关键的 `capture → coalition release → return to coverage` 没有提供前例。
- `distributed feedback optimization` 的 “local information” 是 local cost + neighbor data exchange，并通过 trackers重建 aggregate；它不是 local enemy sensing。

## 8. Relation to CoCap
- **Closest similarities:** concurrent non-capture task + target encirclement；heterogeneous real ground/aerial robots；distributed neighbor communication；safety layer。
- **Fundamental differences:** known static target；no search/detection；no target-wise subgroups；no capture; no release/return/repeated arrivals。
- **Does it cover a candidate novelty?** [AI判断] 覆盖并显著压缩“persistent monitoring + encirclement concurrent”这一宽泛 novelty；**不覆盖 post-capture lifecycle**。
- **Directly reusable ideas:** 把 coverage/monitoring opportunity cost 写入 joint optimization；event-trigger aggregate communication；CBF safety wrapper；micro/macro objective decomposition。
- **Non-transferable assumptions:** known static target、stationary point objective、Vicon/offboard deployment。
- **New research questions exposed:** CoCap可以把 P0010 式 concurrent objective 作为强 classical baseline，但真正新增应在 **target-triggered phase transition + adaptive subgroup release/re-entry**，而不是“两个目标同时优化”。

### P0010 vs P0033
- **P0010:** [原文 + AI判断] 单一已知 static target；全队共同 encirclement，部分 robot有预先 assigned fixed monitoring spots；三目标同时优化；无 detection/capture。
- **P0033 (R-LM-01):** [已有 synthesis] fixed scouts持续 exploration、fixed pursuers做 multi-target pursuit，target信息经通信传播；有 exploration/pursuit并存但角色不动态，且无 post-capture release。
- **Conclusion [AI判断]:** 两者共同证明“非参与/其他任务在 pursuit/encirclement 期间继续”并非空白；但 **dynamic coverage↔capture role lifecycle** 仍未被二者覆盖。
