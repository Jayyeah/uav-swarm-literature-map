# READING NOTE — P0009 — Wen et al. 2024 — FOV-constrained enclosing and tracking

## 1. Paper positioning
- **Problem:** [原文] 多台 uncertain two-wheel nonholonomic mobile robots 围绕并跟踪单一 moving target，同时满足 motion constraints 与 camera field-of-view (FOV) constraints。
- **Main predecessors:** [原文] target enclosing/tracking、nonholonomic trajectory tracking、visibility-constrained multirobot formation。
- **Why this paper was needed:** [原文] fixed cameras 有有限视角，若参考轨迹不兼容，target 会离开 FOV；论文希望从 reference-trajectory design 开始显式保证可见性，再用 prescribed performance bound (PPB) 做 uncertain robot tracking。
- **Genealogy role:** [AI判断] classical side 对“FOV-constrained target enclosing/tracking”的直接 competitor；但它更接近 **visibility-preserving trajectory design**，不是 CoCap/P0034 式 intermittent partial observability。

## 2. Problem setting
- **Agents / targets:** [原文] `N` 两轮 nonholonomic robots；单一 moving target。
- **Target dynamics:** [原文] target 同样为 unicycle：
  `dot x_t=v_t cosφ_t`, `dot y_t=v_t sinφ_t`, `dotφ_t=ω_t`（Eq. (1)）。
  Assumption 1：`v_t,ω_t` continuously differentiable，target trajectory curvature 有上界。
- **Robot dynamics:** [原文] kinematic Eq. (2)；后续 wheel-level model Eq. (24)，输入为左右轮 angular velocities，wheel radius/half-width等参数可未知。
- **Action space:** left/right wheel angular velocity（经 adaptive controller生成）。
- **Sensing / observation:** [原文] 论文声称依赖 onboard relative-position measurement；每 robot 装固定相机，FOV half-angle `β`，要求 target projection `β_ti∈[-β,β]`。
- **Reference-state assumption:** [原文] Sec. III 明确从 **给定 target velocities `v_t,ω_t` 或等价 target trajectory `(x_t,y_t),φ_t`** 推导每台 robot 的 reference trajectory（Eq. (7)–(13)）。全文没有 target-state estimator/belief module。
- **Communication:** [原文 + AI判断] 正文没有提出 inter-robot communication/controller consensus mechanism；算法本体是每台 robot 按预先的 regular-polygon index/reference 跟踪 target-relative trajectory。不能据此反推“无通信即可在真实局部观测下求 target state”，因为 target motion information 本身是 reference generator 的输入。
- **Centralized/decentralized:** [AI判断] low-level tracking 可 per-robot 独立执行；但问题并非严格 decentralized partial-observation estimation。target motion/reference information 的获得机制未建模。
- **Map / obstacles:** 无 environmental obstacles/occlusion model。
- **Target behavior:** smooth moving target，非 strategic evader。
- **Speed ratio:** 无 PE speed-ratio guarantee；只通过 feasible reference geometry满足运动/FOV。
- **Capture / termination definition:** enclosing + tracking reference；没有 interception/capture terminal event。

## 3. Core idea

### Plain-language summary
[原文] 先计算一个 regular polygon reference formation，并选择 formation radius `d(t)`，使每台 nonholonomic robot 的 heading/trajectory既能实现、相机又始终把 target 保持在 FOV；再设计 adaptive PPB controller 使实际 robot 以规定的 transient error bounds 跟踪 reference。

[AI判断] FOV在这里首先是 **几何可行性约束**。方法的目标是从设计上避免 target loss，而不是在 target 已经丢失后维护 belief 或 search/reacquire。

### Mathematical / algorithmic mechanism
目标坐标系下 desired robot 位置：
`[x_i,y_i]^T=d[cosθ_i,sinθ_i]^T`（Eq. (5)），
均匀角位 `θ_0i=π(2i/N-1)`（Eq. (6)）。

世界系 reference（Eq. (9)）：
`q_ri=q_t+d[cos(φ_t+θ_i), sin(φ_t+θ_i)]^T`。

由 target motion 与 `d,\dot d` 得 reference velocities/orientation（Eqs. (10)–(13)）。

FOV feasibility 的核心约束（Eq. (17)）：
`|tan β_ri| = |(dω_t cosθ_i+\dot d sinθ_i)/(dω_t sinθ_i+\dot d cosθ_i-v_t)| ≤ tanβ`。

constant-scale 时得到 `d`/curvature bound（Eqs. (21)–(23)）；作者明确说据此选择 `d=1/κ_max` 可保证 target **continuously visible to all robots**（Sec. III-C / p. 5114）。

## 4. Method details

### Classical control papers
- **Reference trajectory:** [原文] variable `d(t)` 或 constant `d`；若当前 `d` 不满足 FOV/motion constraints，调整 `d` 直到 reference feasible。
- **Tracking controller:** [原文] Sec. V 使用 PPB。tracking errors `z_e, φ_e` 被时间衰减 performance envelope 限制，并在线估计 unknown wheel/model parameters。
- **Core theorem:** [原文] Theorem 1（Sec. V, PDF p. 7）：若使用 control law (47) 且初始 error 满足 prescribed-performance bounds，则 moving target 被 tracked and enclosed with arbitrarily small errors。证明由 Lyapunov derivative `dot V_1=-k_1χ²-k_2γ²`（Eq. (50)）与 Barbalat 得到。
- **Guarantee type:** tracking-error/transient-performance + geometric FOV feasibility；不是 target non-loss under occlusion, and not capture。

## 5. Evidence
- **Simulation only:** [原文] Sec. VI 标题就是 `SIMULATION STUDIES`。使用 3 台 two-wheel robots，camera `β=π/6`。
- **Failure case:** [原文] `d=8 m` 时在大转弯处某些 onboard cameras 的 projection angle 越界，Fig. 4 显示 target 不能被 camera 观察。
- **Feasible constant case:** [原文] `d=3 m` 时全程满足 FOV，Fig. 5。
- **Variable-scale case:** [原文] 动态调整 `d` 可继续满足 motion + FOV，Fig. 6。
- **Comparison:** [原文] 与前序方法 [12] 做 simulation comparison。
- **Physical experiment:** **没有**。
- **Real localization/computation stack:** 无，因为没有 hardware section。

**SCREEN CORRECTION — Real experiment classification.**  
[原文] S-CE-01 screening note 把 P0009 写成“experimental results with mobile robots / Yes”。完整 PDF 核验后应更正：全文只有 Sec. VI `SIMULATION STUDIES`，Figures 4–7 均是 simulation；没有 physical-robot experiment、MoCap stack 或 onboard/offboard deployment section。Abstract 使用了 “Experimental results” 这一宽泛措辞，但 paper body 的证据是 simulation only。

### SCREEN clarification — FOV semantics
[原文 + AI判断] 论文确实演示了坏 reference 会让 target 离开 camera FOV，但 proposed method 的任务是 **预先选择 reference 使它不离开 FOV**。当 target 越界时，没有 observation dropout model、belief update、last-seen memory 或 reacquisition policy；simulation 仍有完整 target trajectory用于计算。因而不能把它等价成 intermittent sensing。

## 6. Limitations

### Author-stated [原文]
- camera mounting angle依 task/robot index 设计；换任务可能需重新调整；作者把统一固定 camera mounting 留作 future work。

### Evidence-visible [原文 + AI判断]
- target motion `v_t,ω_t` 或完整 trajectory 是 reference generation 的输入，但没有说明如何仅靠有限 FOV relative sensor可靠估计这些量。
- 无 sensing range、occlusion、noise、dropout、target-loss recovery。
- 无 inter-agent collision/obstacle guarantee。
- 无 physical experiment。
- 单一目标、无 assignment/subgroup/lifecycle。

### Our inference [AI判断]
- “FOV constrained”在本文意味着 **keep-in-view constraint satisfaction**，不是“policy在 partial observation 下仍工作”。
- 对 CoCap novelty 的影响应限于：**FOV-aware control/reference design 已成熟**；不能用来否定 local/intermittent discovery + uncertainty 的更强问题。

## 8. Relation to CoCap
- **Closest similarities:** onboard-camera/FOV language、moving target、nonholonomic physical constraints。
- **Fundamental differences:** CoCap candidate gap要求 target state 可暂时未知/丢失；P0009 用设计保证 continuous visibility，并把 target motion作为 reference input。
- **Does it cover a candidate novelty?** [AI判断] 杀死“首次考虑 FOV-constrained encirclement”这类 claim；不杀死“intermittent local target observation + belief/reacquisition under limited propagation”。
- **Directly reusable ideas:** FOV feasibility inequality；formation-scale adaptation作为 hard/soft constraint；PPB tracking-error bounds。
- **Non-transferable assumptions:** smooth known/available target motion；single target；无 occlusion/loss process。
- **New research questions exposed:** CoCap若 target 丢失，能否把 P0009 的 keep-in-view feasibility 作为 learned observation management/active sensing objective，而不是假定始终可见。
