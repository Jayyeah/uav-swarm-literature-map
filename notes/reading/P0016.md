# READING NOTE — P0016 — Multiplayer reach-avoid differential games with simple motions: A review

## 1. Paper positioning
- Problem: [原文] 综述多人 reach-avoid（M-RA）微分博弈：多个 pursuers/defenders 保护 goal region，多个 evaders/attackers 从 play region 出发，试图在被捕获前进入 goal region。论文聚焦 Isaacs 意义下的 **simple motion**，并把 barrier / winning region、geometric/HJI 方法与多人 task allocation 串成一个统一谱系。
- Main predecessors: [原文] Isaacs (1965) 的 differential games/barrier；Mitchell et al. (2005) 的 HJI reachable-set computation；Margellos & Lygeros (2011, P0019) 的 reach-avoid HJ 语义；随后的一对一/小规模 barrier 与 multiplayer allocation 工作。
- Why this paper was needed: [原文] M-RA 同时具有“capture 或 goal-entry”非唯一终局和复杂的队内合作/队间竞争；直接 joint-state HJI 随玩家数爆炸。综述的核心组织思路是：**先用小规模 game-of-kind/game-of-degree 得到可捕获证书，再做最优/近似 task allocation。**
- Map role: [AI判断] 本批的 vocabulary/genealogy anchor；真正的 theorem-level 证据仍应回到 P0019、P0024、P0025、P0028。

## 2. Problem setting
- Agents / targets: [原文] `N_p` pursuers `P={P_1,...,P_Np}` 与 `N_e` evaders `E={E_1,...,E_Ne}`；区域 `Ω⊂R^n` 被 `(n-1)` 维分界超曲面 `T` 分为 `Ω_play` 与 `Ω_goal`。（Sec. 2.1, Eq. (1), PDF pp. 2–3）
- Dynamics: [原文] point-mass holonomic simple motion：
  `ẋ_Pi = v_Pi u_Pi`, `ẋ_Ej = v_Ej u_Ej`, `||u||_2≤1`。玩家有速度上界且可瞬时改变 heading。（Eq. (1), p. 2）
- Action space: [原文] instantaneous heading / bounded velocity direction。
- Sensing / observation: [原文] Assumption 2：full-state information；所有玩家位置与速度已知。（p. 2）
- Communication: [AI判断] 综述的 baseline 不是通信受限模型；full-state knowledge 隐含了比 CoCap 更强的信息条件。
- Centralized/decentralized: [原文] 讨论 state feedback、non-anticipative 等 differential-game strategy classes；具体 reviewed method 各异。不能把整篇综述统一标成“decentralized”。（Sec. 2.3.2, p. 3）
- Map / obstacles: [原文] 总体 formulation 允许一般 game region；正文重点结果多是 2D bounded convex、3D half-space、circle/lifeline 等特定几何。障碍并非统一 baseline。
- Target behavior: [原文] evader 试图进入 goal region，同时避免被捕。
- Speed ratio: [原文] Assumption 1 baseline `v_Pi >= v_Ej`。（p. 2）
- Capture / termination definition: [原文] Assumption 3：`||x_Pi-x_Ej||≤r_i` 时捕获；`r_i>0` 为 radius capture，`r_i=0` 为 point capture。evader 退出包括 play region 内被捕、在 splitting hypersurface 上被捕、或先进入 goal region。（pp. 2–3）
- Population / lifecycle: [原文] Assumption 4：pursuer 数量保持不变，直到 play region 中无 evader。综述 Sec. 7.2 明确指出 sequential capture/再分配是现有 formulation 的薄弱处。（pp. 2, 9）
- Team objective: [原文] 令 `J` 为在 play region 中被捕获的 evader 数，团队 saddle-point objective 写为 `max_{Σ_P} min_{Σ_E} J = min_{Σ_E} max_{Σ_P} J`。（Eq. (2), p. 3）

## 3. Core idea
### Plain-language summary
[原文] 这篇 review 最重要的不是某一个新控制器，而是给出 M-RA 的“求解分层”：

1. 先回答 game of kind：某个初始状态到底属于 pursuer winning region 还是 evader winning region；
2. barrier 是二者分界；
3. 在 simple motion 下，可用 dominance geometry / Apollonius / analytical barrier 或 HJI 求出小规模 game 的 winning certificate；
4. 把“某个 pursuer coalition 是否能保证拦下某个 evader”作为 assignment 的可行边；
5. 再做 constrained matching / integer programming 来处理多人。

[AI判断] 对 CoCap 最关键的抽象不是“距离近就支援”，而是 **certificate → feasible edge → allocation**。

### Mathematical / algorithmic mechanism
#### Game of kind vs game of degree
- [原文] game of kind：给定 winning condition，判谁能保证获胜；输出是 win/lose region。
- [原文] game of degree：在胜负语义已知后，进一步优化 capture time、goal distance 等 payoff，求 saddle-point strategy。（Sec. 2.3, p. 3）

#### Barrier / winning regions
对“multiple pursuers vs one evader”，综述给出：
- [原文] PWR `W_P`：存在 pursuer-team strategy，使得对任意 evader input 都能在 evader 进入 goal 前获胜；
- [原文] EWR `W_E`：存在 evader strategy，使得对任意 pursuer-team strategy 都能到达 goal；
- [原文] barrier `B`：分隔这两个 winning regions 的 game-state surface。（Sec. 2.3.1, p. 3）

[AI判断] 这里的核心是量词 `∃ strategy, ∀ opponent control`；所以 “当前几何看起来包围” 不是 winning certificate。

#### Dominance region is a different object
- [原文] dominance region 定义在**物理空间**：某玩家能够比对手更早到达的点集。equal speed/point capture 时可变为 Voronoi cell；unequal speed/point capture 时出现 Apollonius circle；带 capture radius 可用 function-based dominance region。（Definitions 1–3, Sec. 3.1, p. 4）
- [AI判断] dominance region 是构造 winning/barrier 的几何 primitive，不应与 PWR/EWR、reach-avoid set、capture region 同义替换。

#### HJI branch
[原文] 对 joint state `x=(x_P1,...,x_PNp,x_E1,...,x_ENe)`，终端集合 `M={x|g(x)≤0}`、terminal payoff `Φ(x(t_f))`，value function 在零和条件下满足 HJI：

`min_{u_e} max_{u_p} H(x,λ,u_p,u_e) = max_{u_p} min_{u_e} H(x,λ,u_p,u_e) = 0`,

其中 `H=λ^T f`, `λ=∇V`。（Eq. (4), p. 4）

simple motion 下 minimax Hamiltonian：

`H*(x,λ)=Σ_i v_Pi ||λ_Pi||_2 - Σ_j v_Ej ||λ_Ej||_2`。（Eq. (5), p. 4）

characteristic equations：

`ẋ = ∂H*/∂λ = f*`, `λ̇ = -∂H*/∂x = 0`。（Eq. (6), p. 4）

因此 regular equilibrium trajectories 为 straight lines，regular controls 为常值；boundary costate 由 `λ=∇Φ+μ∇g` 给出。（Eq. (7), p. 5）

[AI判断] 这是 simple-motion analytical geometry 为什么成立的动力学基础之一；换成 UAV acceleration/turn-rate 后不能直接继承。

## 4. Method details
### PE papers
- Game formulation: [原文] reach target while avoiding capture；pursuers protect goal by interception。
- Payoff: [原文] game-of-kind winner + game-of-degree quantitative payoff；team-level Eq. (2) maximizes captured evaders。
- Winning/capture region: [原文] PWR/EWR/barrier；在 reviewed 2D convex case，barrier 可由 active pursuers 构造。（Sec. 4.1）
- Equilibrium / HJI / Apollonius / other geometry:
  - [原文] 2D convex, faster pursuers, point capture：one-active-pursuer barrier Eq. (8)，two-active-pursuer barrier Eq. (9)；**若 active pursuers >2，underlying barrier 上任一点由至多两个相邻 active pursuers 决定**，因此可拼接 pairwise barriers。（Sec. 4.1.2, p. 5）
  - [原文] 3D heterogeneous/radius-capture branch：evader dominance region 与 goal region 相切给 barrier；离 goal 最近点由至多三个 pursuers 决定。（Sec. 4.2.2, p. 6）

### Task allocation
[原文] Sec. 5 把每个 pursuit coalition `P_c` 看成 assignment-side node，把 evader `E_j` 看成另一侧 node。只有当 coalition 可以在 goal-entry 前保证捕获 `E_j` 时才存在 edge `e_cj`。不同 coalition 若共享 pursuer 就冲突。Eq. (18) 给出 constrained 0–1 matching / ILP：最大化被分配且保证可捕获的 evaders，同时约束每个 evader 最多一个 coalition、每个 coalition 最多一个 evader、互相冲突的 coalitions 不能同时选。（Sec. 5.1, p. 8）

[原文] 该一般 constrained matching 为 NP-hard；综述引用后续工作给出 constant-factor / sequential matching approximation，说明多人可扩展性需要“certificate decomposition + combinatorial approximation”，而不是 joint-state HJI。（Sec. 5.2, p. 8）

## 5. Evidence
- Baselines: review，不是单个实验论文。
- Metrics: 不适用统一实验指标；核心比较维度是 barrier/winning-region exactness、task-allocation guarantee、计算复杂度。
- Ablations: 不适用。
- Simulation / Real experiment: [原文] 综述汇总已有工作；不应把被综述论文实验当作本 review 的新实验贡献。
- Scalability/generalization: [原文] HJI 对 joint state 的维数灾难是主要瓶颈；simple-motion analytical barriers 和 allocation decomposition 是绕开它的主要路线。

## 6. Limitations
### Author-stated [原文]
Sec. 7 明确列出：
- player dynamics：simple motion 忽略 minimum turning radius、maximum acceleration、external forces；（Sec. 7.1, p. 9）
- sequential capture：现有 barrier 通常 myopic 地看当前 capture，较少考虑捕获后继续追击；（Sec. 7.2, p. 9）
- spatial-temporal coupling：assignment 往往把多个 pursuit-evader 子游戏当独立，但真实轨迹时空耦合；（Sec. 7.3, pp. 9–10）
- fast evaders：pursuer 不再有速度优势时问题本质改变，需要多人合作/边界几何；（Sec. 7.4, p. 10）
- partial information：full-state 假设在有限 detection range、measurement error、dense swarm 下不现实。（Sec. 7.5, p. 10）

### Evidence-visible [原文 + AI判断]
- 绝大多数 clean analytical certificate 依赖 simple motion、精确速度比、已知几何与强信息。
- task allocation 的“可行边”通常是 binary，缺少对 sensing uncertainty/model mismatch 的概率/鲁棒余量。

### Our inference [AI判断]
- CoCap 不应该直接复制 barrier formula；更合理的是学习/估计一个 **soft robust capturability margin**，让经典 certificate 成为 teacher/prior，而不是在线硬规则。
- “coalition 能保证拦截”与“coalition 当前更值得去支援”仍不同：后者还需考虑机会成本、未观测目标、coverage loss、动态到达等。

## 7. Literature lineage
- Important predecessors:
  - Isaacs (1965): barrier, game of kind/degree, simple motion。
  - Mitchell et al. (2005, P0018): time-dependent HJI reachable sets。
  - Margellos & Lygeros (2011, P0019): reach-avoid with state constraints。
- Same-era / core descendants reviewed:
  - Chen et al. (2017, P0024): pairwise outcome → maximum matching。
  - Yan et al. (2020, P0025): analytical coalition barriers → constrained assignment。
  - Yan et al. (2022, P0026): heterogeneous 3D/radius-capture + matching extension。
- [AI判断] 谱系不是一条线：numerical pairwise-HJI branch 与 analytical-barrier/coalition branch 是两条不同的 scalability 路线。

## 8. Relation to CoCap
- Closest similarities: multi-target adversarial pursuit、动态队内资源分配、coalition/support 概念。
- Fundamental differences: CoCap 面向 local/intermittent sensing、unknown/strategic target、UAV action/dynamics、persistent coverage↔capture lifecycle；review baseline 多为 full-state + simple motion + one-shot/independent subgames。
- Does it cover a candidate novelty?: [AI判断] 它覆盖了“基于可捕获性做 task assignment”这一一般思想，因此 CoCap 不能把 **capability-aware assignment 本身**当 novelty。
- Directly reusable ideas:
  1. **capturability certificate → assignment edge** 的模块化接口；
  2. barrier/winning-region 与 dominance-region 的术语区分；
  3. 用低维 certificate 避免全局 joint-state curse of dimensionality。
- Non-transferable assumptions: full-state、pursuer≥evader speed、simple motion、known model、convex/clean geometry、静态 one-shot allocation。
- New research questions exposed: 如何在局部感知和不确定 dynamics 下在线估计 coalition capturability margin，并在 repeated target arrival / coverage duty 下动态招募 support？

### Potential CoCap implementation candidates
1. `C(S,j)`：给 coalition `S` 与 target `j` 的 soft capturability score，作为 target selection/support gate 的先验或 auxiliary target。
2. 训练 curriculum 以经典 barrier margin 分层：easy PWR deep interior → near barrier → model mismatch/local sensing/fast evader。
3. evaluation 增加 certificate-aware metric：同等 initial state 下，“被分配 coalition 中多少在 teacher model 下可捕获 / margin 多大”，而非只统计距离或最终 capture。
