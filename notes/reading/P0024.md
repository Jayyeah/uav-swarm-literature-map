# READING NOTE — P0024 — Multiplayer Reach-Avoid Games via Pairwise Outcomes

## 1. Paper positioning
- Problem: [原文] 在带 obstacles 的 compact 2D domain 中，`N_A` attackers 试图让其中 `M` 个到达 target，`N_D` defenders 通过 capture 或 indefinitely delay 阻止。full multiplayer HJI 不可计算，因此论文先求所有 1v1 pairwise outcomes，再用 maximum bipartite matching 合成为多人 defender guarantee。
- Main predecessors: [原文] 低维 HJI reach-avoid、level-set computation、MILP/NMPC/approximate-DP multiplayer approximations。
- Why this paper was needed: [原文] exact HJI complexity 随 joint-state dimension 指数增长；但 1v1 game 仍可 tractably 得到 robust winner certificate。作者把多人问题降为固定维度 pairwise certificate + graph matching。
- Map role: [AI判断] “pairwise certificate → scalable assignment”分支的 canonical paper；它证明 assignment 不一定需要直接求多人 joint game，但其 guarantee 是 conservative defender lower bound，而不是 full-game global optimum。

## 2. Problem setting
- Agents / targets: [原文] `N_A` attackers `P_Ai`、`N_D` defenders `P_Dj`，位于 bounded open domain `Ω⊂R^2`；`Ω=Ω_free∪Ω_obs`，target `T⊂Ω_free` compact。（Sec. II-A, PDF p. 2 / IEEE p. 1452）
- Dynamics: [原文]
  `ẋ_Ai=v_Ai a_i`, `ẋ_Dj=v_Dj d_j`, controls are measurable functions taking values in unit disk `B_2`。（Eq. (1), p. 2）
- Action space: bounded planar velocity/simple motion。
- Sensing / observation: [AI判断] HJI winner checks require current pair states and known dynamics/domain; paper不是 partial-observation formulation。
- Communication: not the modeled bottleneck；team strategy construction assumes pair outcomes/assignments available。
- Map / obstacles: [原文] explicit obstacles `Ω_obs`; players must remain in `Ω_free`。
- Target behavior: [原文] attackers adversarially seek target; no fixed straight-line prediction required by HJI pairwise method。
- Speed ratio: [原文] HJI branch allows general player dynamics/speeds within numerical model；path-defense approximation assumes defender not slower, `v_A≤v_D`。（Sec. IV, p. 2）
- Capture / termination: [原文] `C_ij={x:||x_Ai-x_Dj||_2≤R_C}`；attacker wins by reaching T without capture；defender wins by capture **or indefinitely delaying** attacker from T。（Sec. II, p. 2）
- Team terminal objective: [原文] attacking team wins when `M` attackers reach T；defending team wins if it can prevent `N_A-M+1` attackers from reaching T。
- Solution object: pairwise 1v1 defender-winning outcome; then matching size gives team guarantee。

## 3. Core idea
### Plain-language summary
[原文] 对每个 defender–attacker pair，先问一个独立 1v1 reach-avoid 问题：“这个 defender 在最坏对手策略下能否保证挡住这个 attacker？”若答案是 yes，就在 bipartite graph 中连边。之后 maximum matching 选择互不冲突的 defender–attacker pairs。

[AI判断] 它把 **能力判断** 与 **资源分配** 分开：edge 是 certificate，matching 只是组合 certificates。这个接口对 CoCap 很重要，但它只允许“一名 defender 负责一个 attacker”，不表达“单人不够、两人 coalition 才够”的 support recruitment。

## 4. Method details
### 4.1 Pairwise HJI certificate
[原文] 1v1 joint state `x=(x_A,x_D)`。作者定义（Sec. III, Eq. (3), p. 2）：

`R = {x∈Ω^2 | x_A∈T} ∪ {x∈Ω^2 | x_D∈Ω_obs}`

`A = C ∪ {x∈Ω^2 | x_A∈Ω_obs}`.

这里 `R` 是 attacker 的 target set，`A` 是 attacker 必须 avoid 的 capture/attacker-obstacle set。计算 infinite-horizon 4D reach-avoid set `RA_∞(R,A)`：
- [原文] `x^0∈RA_∞`：attacker 即使面对 optimal defender 也能 guarantee win；
- [原文] `x^0∉RA_∞`：defender 用 optimal control 可 guarantee win。（Sec. III, p. 2）

[AI判断] 因此 pairwise defender-feasibility edge 本质上是 `1[x^0∉RA_∞]`。

### 4.2 Path-defense approximation
[原文] 为降低 4D HJI 的计算，Sec. IV 提出 path defense：用 target-side separating shortest path `P̄(e_a,e_b)` 与 2D Eikonal/FMM 计算 conservative defender-winning slices。
- Definition 3/4：defendable / strongly defendable path；后者要求 defender 有策略在有限时间到 path 并阻止 attacker 穿过。
- Lemma 1：当 defender 初始就在 path、`v_A=v_D` 时，strong defendability 等价于 attacker 在 induced regions `R_a∪R_b` 之外；若 `v_A<v_D`，该条件是 sufficient。（Sec. IV-B, p. 3）
- Lemma 2：只需检查特殊 first-arrival point `p*`，无需枚举整个 path。（p. 4）
- Algorithm 1：对 enclosing target 的多个 paths 求 defender winning regions 并取 union，得到 conservative 2D slice。（p. 4）

### 4.3 Pairwise graph → maximum matching
[原文] **Algorithm 2, Sec. V-A, PDF pp. 4–5 / IEEE 1454–1455**：
1. 构建 attacker nodes 与 defender nodes 的 bipartite graph；
2. 若 `P_Di` 在 1v1 reach-avoid game 中能 win against `P_Aj`，则连 edge `(D_i,A_j)`；
3. 求 maximum matching。

#### The guarantee the SCREEN stage asked to verify
[原文] 论文在 Algorithm 2 后**以正文陈述 guarantee，而不是编号 theorem/proposition**：

若 maximum matching 大小为 `m`，defending team **能够阻止至少 `m` 个 attackers 到达 target**；因此 `N_A-m` 是能到达 target 的 attackers 数量的 upper bound。（Sec. V-A, p. 5）

[AI判断] 所以准确语义是：
- matching cardinality `m` = **guaranteed prevented attackers 的 lower bound**；
- `N_A-m` = attackers reaching target 的 **upper bound**；
- 它不是 full `N_A` vs `N_D` differential game 的 global optimum theorem。

如果 `m ≥ N_A-M+1`，则按论文 team winning definition，defenders 已有 certificate 足以阻止 attacking team 达成“M 个到 target”。

### 4.4 Why simultaneous pairwise games can be composed
[原文] matching 保证每个 defender 和 attacker 至多出现在一个选中 pair。每个 matched defender 只需执行其 pairwise winning strategy。（Sec. V-E, p. 5）

[原文] paper 允许不同 defenders 使用不同 pairwise strategy（optimal HJI、semi-open-loop path-defense 或其他已知保证策略）；其 competence 先被编码为 graph edges，再由 matching 合成 team strategy。

[AI判断] 可组合 guarantee 的关键不是“pairwise winning 自动等于 multiplayer winning”，而是：
1. selected pairs **player-disjoint**；
2. 每个 selected defender 已有针对对应 attacker 的 worst-case 1v1 guarantee；
3. defender 的任务只需确保这些 matched attackers 各自被 capture/delay。

这不利用也不证明真正 multi-defender synergy；因此是 conservative decomposition。

### 4.5 Dynamic rematching
[原文] **Algorithm 3, Sec. V-B, p. 5** 每隔 `Δ` 更新所有 pair outcomes 与 maximum matching。`Δ→0` 时，如果每个 matched defender 始终应用 pairwise winning control，**maximum matching size can never decrease**。（p. 5）

[AI判断] 这是 dynamic assignment 的有价值先例，但仍是 pairwise feasibility，不是 local sensing 下的在线 coalition recruitment。

### 4.6 Complexity / avoiding curse of dimensionality
- [原文] joint multiplayer HJI 会在 `2(N_A+N_D)`-dimensional joint state 上爆炸。
- [原文] pairwise HJI 只需固定 4D PDE；heterogeneous pairs 一般需 `N_A N_D` 次，成本 `C N_A N_D`；若每队 dynamics 相同，一次 4D solution 可用于所有 pair-state lookup。（Sec. V-C, p. 5）
- [原文] path-defense 对 fixed domain/target 的主要 computation 为 `C_1+C_2 N_A` 级别，并比 4D HJI 更 scalable。（Sec. V-D, p. 5）

[AI判断] 这里绕开的是 **state dimension with player count**，不是让所有 computation 变成常数；pair count 与 graph matching 仍随人数增长。

## 5. Evidence
- Numerical example: [原文] 4v4 square domain with obstacles, equal max speed, capture radius 0.1。（Sec. VI, p. 5）
- HJI results: [原文] 4D HJI computes pairwise RA slices；maximum matching size 3 in shown initial state，因而保证 at most one attacker reaches target。（Figs. 6–7, pp. 5–6）
- Path-defense: [原文] conservative slices smaller，但仍给 guarantee；作者报告在其 example 上采用不同 path discretizations 的 computation/area coverage tradeoff。（p. 6）
- Dynamic matching: [原文] Fig. 9 展示 maximum matching 随 time 增大；when it reaches 4, all attackers can be prevented。（p. 6）
- Real experiment: none。

## 6. Limitations
### Author-stated / evidence-visible [原文]
- full multiplayer exact solution remains computationally intractable；方法是 approximation/decomposition。（Abstract, Conclusion）
- path-defense adds conservatism toward defender；HJI 4D pairwise method更准确但计算更重。
- method’s cooperation is based on combining **1v1 competences**；不会生成一个需要 2+ defenders 才能成立的 pairwise edge。

### Our inference [AI判断]
- maximum matching guarantee can be strict lower bound；未匹配 attacker 并不代表一定会 escape，只是没有从该 decomposition 得到 guarantee。
- 若一个 target 需要 coalition cooperation 才可捕获，P0024 会把所有 individual edges 判 false，即使 2v1 实际可赢；这正是 P0025 解决的结构性缺口。
- 信息结构、observation uncertainty、communication delay 未进入 certificate；CoCap 的 local sensing 下 pair outcome 只能被估计。

## 7. Literature lineage
- Important predecessors: HJI/reachability line including P0019；path-defense / fast marching methods。
- Direct conceptual descendants / complement:
  - P0025：不止 1v1 edge，而是 1- or 2-pursuer coalition feasibility → constrained 0–1 assignment；在其特定 simple-motion convex model 中得到 stronger global-optimality statement。
  - subsequent robust/receding-horizon pairwise-outcome defenses（P0016 review references Deng et al. 2021 等）。

## 8. Relation to CoCap
- Closest similarities: multi-target, online assignment, pairing can change over time, obstacle-aware pair certificate。
- Fundamental differences: CoCap 的 support 是多人 coalition；target sensing 是局部/间歇；还有未参与者 coverage 与 post-capture return。
- Does it cover a candidate novelty?: [AI判断] 覆盖了“pairwise capturability + dynamic matching”这一 idea，因此 CoCap 若只把 pairwise distance/capability 送进 Hungarian/matching 并不新。
- Directly reusable ideas:
  1. 把 pair/coalition feasibility 与 assignment solver 解耦；
  2. online rematching，而不是 episode 开始固定分配；
  3. guarantee metric 用“guaranteed prevented count / upper bound on escaped count”。
- Non-transferable assumptions: known pair state/model、pairwise sufficiency、central graph construction、无 persistent coverage opportunity cost。
- New research questions exposed: 如何把 pairwise edge 扩展成 `coalition-target hyperedge / soft feasibility`，同时保持 online、local-information 与 scalable？

### Potential CoCap implementation candidates
1. 先做一个 **dynamic bipartite baseline**：每个 agent-target edge 用 learned pair capturability，而非距离；与当前 `U_ij` 比较。
2. 再升级为 coalition score：若 pair score 不足，support gate 评估加入一个 neighbor 后的 capturability 增益。
3. evaluation 记录 `matching lower bound` 类指标：根据 learned/teacher certificate，当前分配理论上可覆盖多少 targets，和实际 captures 比较 calibration。
