# READING NOTE — P0034 — Limited-FOV urban multi-UAV pursuit with MARL

## 1. Paper positioning
- Problem: [原文] Multiple pursuit UAVs must **search for, reacquire, and physically capture** one faster unauthorized UAV in an urban obstacle field, while target information is only initially available through finite-range, finite-angle, obstacle-occluded visual fields.
- Main predecessors: [原文] Visibility-based pursuit-evasion; classical differential-game/cooperative-control PE; MARL; graph attention; Soft Actor-Critic.
- Why this paper was needed: [原文] Most PE work assumes real-time opponent state or treats first visual contact as success. This paper instead requires active search under limited visibility and then close-proximity capture.
- [AI判断] For CoCap, this is the strongest direct precedent in this batch against any standalone novelty claim based on “local/FOV-limited target sensing.”

## 2. Problem setting
- Agents / targets: [原文] \(N\) homogeneous pursuer UAVs vs one evasion UAV in bounded 2-D urban airspace.
- Dynamics: [原文] Eq. (1):

\[
\dot x=v\cos\psi,\qquad \dot y=v\sin\psi,\qquad \dot\psi=\omega,\qquad \dot v=a.
\]

- Action space: [原文] Continuous \(u_i^t=[\omega_i^t,a_i^t]\), bounded by maximum angular velocity and acceleration; AirSim `Simple_Flight` executes commands every second in experiments.
- Sensing / observation: [原文] Each pursuer has a forward sector FOV with finite radius \(L\), viewing angle \(\phi\), and line-of-sight occlusion by buildings. It also has five obstacle radar rays (front, ±30°, ±60°). The base actor observation includes own state, all teammate-relative state, and phase-dependent evader/lost-point state.
- Communication: [原文] Assumption 1 states pursuer communication is normal throughout the whole area/time. When one pursuer detects the evader, its coordinates are shared with the other pursuers (Fig. 2 caption and phase formulation).
- Centralized/decentralized: [原文] NAGC uses centralized training and decentralized execution. Actor decisions use local observations; the centralized critic/global state includes all pursuers and the evader during training.
- Map / obstacles: [原文] Multi-building urban airspace; buildings block both motion and line of sight.
- Target behavior: [原文] Evaluation includes random maximum-speed motion, a repulsive-force reactive strategy, and a separately pretrained DDPG evader.
- Speed ratio: [原文] Table I: evader 12 m/s; pursuers 9–11 m/s, so the evader is faster.
- Capture / termination definition: [原文] Eq. (4):

\[
\|p_i^t-p_e^t\|_2\le \delta_{cap},\qquad \exists i\in P.
\]

Any one pursuer entering the capture radius succeeds. Table I uses \(\delta_{cap}=15\) m. The episode terminates on successful capture, pursuer collision/out-of-bounds, or the 180 s limit.

## 3. Core idea
### Plain-language summary
[原文] The key task decomposition is **search → pursuit → reacquisition**, with reacquisition split into an approach-to-last-seen-point stage and a suspect-area search stage. NAGC is then trained with phase-specific rewards so the same team can learn each part of that lifecycle under literal intermittent visibility.

[AI判断] The task semantics matter more than the normalizing-flow/GAT architecture: the paper proves that MARL-based UAV pursuit can already include finite sensing distance, finite viewing angle, building occlusion, target loss, and reacquisition.

### Mathematical / algorithmic mechanism
#### Limited visual field
[原文] Eq. (3) models a sector-shaped visual field \(V_i\) with fixed radius \(L\) and angle \(\phi\), aligned with the pursuer yaw. Actual visibility is a subset because building line-of-sight intersections remove occluded points.

Experimental values (Table I):
- \(L=200\) m;
- \(\phi=120^\circ\);
- radar maximum ray length \(\lambda_{max}=100\) m;
- warning distance \(\delta_w=25\) m.

#### Phase machine
[原文] Section IV-A and Fig. 3 define:
1. **Search**: evader has never been detected.
2. **Pursuit**: evader is currently visible to at least one pursuer.
3. **Reacquisition (approach)**: evader was seen but is now lost; pursue the last observed point \(\beta\).
4. **Reacquisition (search)**: after reaching \(\beta\) without redetection, search the suspect area.

[原文] If lost time is \(t_{lost}\) and target maximum speed is \(v_{e,max}\), the suspect area is a circle centered at \(\beta\) with radius \(t_{lost}v_{e,max}\).

[原文] Fig. 3 explicitly states initial Search→Pursuit is unidirectional: once the target has been detected, the system never returns to the original search phase during that episode; Pursuit↔Reacquisition is bidirectional.

## 4. Method details
### RL/MARL papers
- Observation: [原文] Section IV-B:
  - own state: position, yaw, velocity, 5 radar-ray returns;
  - teammates: relative coordinates, distance, relative yaw and azimuth for allied pursuers;
  - evader slot in Pursuit: evader-relative position/distance/azimuth;
  - Reacquisition-approach: last-point-relative position/distance/azimuth;
  - Search or Reacquisition-search: target slot is zero.
- Action: [原文] \([\omega,a]\).
- Reward: [原文] Phase differentiated.
  - Search Eq. (12): rewards covered visual-field area \(A_c^t\), with sign depending on whether coverage improves.
  - Search Eq. (13): rewards newly explored area \(A_n^t\).
  - Pursuit Eq. (14): distance-based shaping over pursuer–evader distances.
  - Pursuit Eq. (15): yaw alignment \(r_{p2}^t=\sum_i C_5\cos(\psi_i^t-\rho_{ie}^t)\).
  - Reacquisition-approach: same pursuit structure with evader state replaced by lost point \(\beta\).
  - Reacquisition-search Eq. (16): rewards visible-area coverage ratio inside the expanding suspect disk \(\pi(t_{lost}v_{e,max})^2\).
  - Collision warning Eq. (17): front-radar proximity penalty.
  - Terminal high success reward \(r_{win}\) and high failure penalty \(r_{fall}\).
- Architecture: [原文] Normalizing-flow actor + “obstacle-target” graph-attention critic (NAGC).
- Actor/Critic/Q: [原文] SAC-family stochastic actors; centralized Q critic. Actor objective is Eq. (35); Q loss Eq. (33); entropy temperature Eq. (36).
- CTDE: [原文] Yes. Training global state contains all pursuers and evader; execution actors consume their own observations.
- Replay/on-policy: [原文] Off-policy replay-buffer training.
- Curriculum/exploration: [原文] Phase-specific reward design supplies structured search/reacquisition behavior; experiments also test changed maps and team sizes.

### Information-flow audit
- [原文] Initial target detection is genuinely constrained by each pursuer's FOV/range/occlusion.
- [原文] After **any** pursuer detects the target, the evader coordinate is shared with the rest of the pursuit team.
- [AI判断] Therefore:
  - `local detection = YES`;
  - `strict local target knowledge after detection = NO`;
  - `limited target-state communication = NO` in the base setting.
- [AI判断] This distinction is central to CoCap. “Only detected locally at first” cannot be used as shorthand for “each actor only knows targets it personally/locally senses.”

### Capturability / coalition audit using R-PE-01
- [原文] Capture is any-one-agent proximity, Eq. (4).
- [AI判断] There is no coalition-size sufficiency test, angular closure, winning region, reach-avoid value, or group feasibility predicate.
- **No coalition capturability certificate.**
- There is no target assignment because the task has one target.

## 5. Evidence
- Baselines: [原文] Four MARL baselines are compared against NAGC; the paper studies architecture variants and multiple evasion strategies.
- Metrics: [原文] Success rate, task duration/capture efficiency, collision-related performance and phase behavior.
- Ablations: [原文] Normalizing-flow and graph-attention components are separately analyzed; supplementary material contains complexity and visibility details.
- Simulation: [原文] High-precision AirSim urban simulation using Parrot AR.Drone-style parameters. Table I: FOV 200 m/120°, capture radius 15 m, evader 12 m/s, pursuers 9–11 m/s.
- Real experiment: [原文] None; evidence is simulation.
- Scalability/generalization: [原文] Tests include unfamiliar obstacle maps and larger pursuer teams. For larger teams, the observation interface is kept fixed by retaining only the two nearest teammates for communication/input. The paper also demonstrates transfer of the algorithmic architecture to static multi-target search and multi-UAV navigation; this is **not** multi-target moving-target pursuit.

## 6. Limitations
### Author-stated [原文]
- The formulation ignores target-positioning delay/error once a target is visible; assumes area-wide reliable team communication; uses planar same-altitude motion.

### Evidence-visible [原文 + AI判断]
- Single target only.
- Team-wide target coordinate sharing follows any local detection.
- Critic sees global evader state during training.
- Capture is one-agent distance threshold, not multi-agent enclosure/no-escape.
- Initial search is not a persistent coverage mission after first discovery.
- Capture terminates the episode; no recovery to search/coverage.
- Learned DDPG evader is evaluated but is separately trained, not co-evolved/self-played with pursuers.

### Our inference [AI判断]
- P0034 **kills** novelty for finite target-sensing range, finite FOV, urban occlusion, pre-detection search, and lost-target reacquisition in MARL-based UAV pursuit.
- It leaves substantial room on multi-target allocation, strict post-detection local knowledge, capacity/capturability-aware support recruitment, geometric capture, and persistent coverage after capture.

## 8. Relation to CoCap
- Closest similarities: local/intermittent target detection, active search, occlusion, faster evader, multiple pursuers, obstacle avoidance, acceleration+turn-rate action, decentralized actor execution.
- Fundamental differences: one target; target coordinates become team-wide known after any detection; no subgroup allocation/support; capture is any-one proximity; no persistent coverage or post-capture return.
- Does it cover a candidate novelty? **Yes, strongly** for local FOV/range/occlusion and search/reacquisition. **No** for strict local target knowledge, multi-target resource allocation, capturability-aware recruitment, multi-agent no-escape capture, persistent recovery.
- Directly reusable ideas: explicit phase machine; lost-point and expanding suspect-area representation; FOV+occlusion simulator; phase-specific reward gating.
- Non-transferable assumptions: full-area reliable communication and instant/error-free team sharing of target coordinates.
- New research questions exposed: Can CoCap retain P0034-style search/reacquisition while replacing global target sharing by local/neighbor belief propagation and making the support coalition itself dynamic?
