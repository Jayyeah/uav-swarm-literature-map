# READING NOTE — P0012 — Liu et al. 2026 — Noisy-range aerial encirclement → interception

## 1. Paper positioning
- **Problem:** [原文] 两台 guardian MAV 用 noisy range measurements 估计 non-cooperative 3-D hostile target 的状态，并从保护 cooperative target 的 encirclement 自适应切换到 hostile-target encirclement、interception/takedown。
- **Main predecessors:** range-only localization/encirclement、anti-synchronization (AS) control、Kalman filtering、aerial interception。
- **Why this paper was needed:** [原文] 现有 range localization与 tracking 往往不直接 engagement；作者希望用 minimal range sensing + active observability trajectory，把 estimation 与 actual aerial interception连起来。
- **Genealogy role:** [AI判断] classical/control side 的 strongest perception-driven `encirclement → interception` bridge，与 R-PE-01 P0028 的 game/no-escape bridge互补。

## 2. Problem setting
- **Agents / targets:** [原文] 两台 guardian MAV；一个 cooperative protected Target 1；一个 hostile non-cooperative Target 2。不是一般 multi-target allocation问题，而是固定“保护对象 + 单威胁”结构。
- **Guardian dynamics:** [原文] discrete-time 3-D point-mass/double-integrator approximation，state `X_i=(p_i,v_i)`，control `u_i∈R³` 为 acceleration（Eq. (1)）。
- **Target dynamics:** [原文] 两个 target也用 Eq. (2) double-integrator；acceleration 是 stochastic disturbance。Hostile acceleration服从 heavy-tailed mixture：多数温和、少数大机动，作者用以模拟偶发 aggressive escape。
- **Action space:** 3-D acceleration，controller考虑 guardian input/flight-speed constraints。
- **Sensing / observation:** [原文] Hostile Target 2 不共享 state；每 guardian onboard sensor测 noisy range/squared distance。Protected Target 1 则向 guardians共享自己的 full state。
- **Self state/localization:** [原文] guardians能把 local frame与共同 inertial frame `W` 对齐，并通过 onboard self-localization（如 VIO/optical flow）实时更新 `p_i`；accumulated self-localization error不在本文考虑。
- **Communication:** [原文] 两 guardian之间有 communication；两者的 range measurements/relative baseline共同形成 estimator observation。
- **Estimator/global reconstruction:** [原文] 两个 squared ranges作差，结合 guardian positions，形成对 hostile state 的 linear time-varying scalar observation `Y=C(k)\bar X_2+\barη`（Eq. (9)），Kalman filter Eqs. (10)–(13) 重建 hostile 3-D position + velocity。Remark 1 给出无需 global guardian positions、只需 guardian relative position `q_12` 的 relative-state estimator 版本。
- **FOV/occlusion/target loss:** 无 explicit FOV、occlusion或 target-dropout model；raw measurement是 range。
- **Target strategic?** [原文 + AI判断] hostile 是 non-cooperative、stochastic maneuvering，可有 aggressive escape-like acceleration，但不是 minimax/game-theoretic strategic evader。
- **Capture / termination definition:** [原文] Definition 2：当 encirclement radius `r(k)≤r_c` 时 hostile 被定义为 captured/taken down。hardware demonstration最终通过 direct impact neutralize。

## 3. Core idea

### Plain-language summary
[原文] Guardians先围绕 protected target做一个带三维上下振动的 anti-synchronization orbit；这种持续变化的 baseline故意制造 persistent excitation，让仅有 noisy ranges 也足以估计 hostile target。威胁靠近时，controller按距离 zone切换：先从保护对象转去围 hostile，再进入 takedown zone 后主动缩小 encirclement radius，最终撞击/neutralize。

[AI判断] 这是一个真正的 **perception-aware hybrid interception pipeline**，但“capture”的 formal guarantee强度要和 P0028 区分：P0012严格证明的是 observability/estimation 与 encirclement-error bounded convergence；并没有“对任意 admissible evader strategy必然 capture”的 game theorem。

### Mathematical / algorithmic mechanism
**Active observability shape:**  
`ζ(k)=r(k)[sin(ρkπ), cos(ρkπ), h(k)]^T`（Eq. (5)），并假设/设计 `{ζ(k)}` persistently exciting（Assumption 1）。

**Range-to-linear observation:**  
`Y=-1/2[(\hat d_1^2)^2-(\hat d_2^2)^2-p_1^Tp_1+p_2^Tp_2] = C(k)\bar X_2+\barη`（Eq. (9)），其中 `C(k)=q_12^T[I 0]`。

**Kalman target-state estimator:** Eqs. (10)–(13)。

**Three controller modes (Sec. 3.2):**
- Case 1 / far zone: Eq. (14)，固定 `r=r_1`，encircle protected Target 1；
- Case 2 / warning zone: Eq. (15)，切换到 estimated hostile Target 2，固定 `r=r_1`；
- Case 3 / takedown zone: Eq. (16)，继续 hostile encirclement，同时
  `r_{k+1}=r_k-(r_1-r_c)/t_in`
  按 user-defined interception time 收缩到 `r_c`。

## 4. Method details

### Classical control papers
- **Estimator:** Kalman filter on LTV system。
- **Uniform observability:** [原文] Definition 3 + Lemmas 2–3：ASATC产生的 guardian relative position `q_12` 保持 PE，从而 target estimation system uniformly observable。
- **Theorem 1:** [原文] TSE 下 hostile state estimation mean-square error exponentially converges to bounded region `\hat ε`（Sec. 3.3, PDF p. 5）。
- **Theorem 2:** [原文] Eq. (14) 下 protected-target AS encirclement error mean-square exponentially converges to region `ε_1`。
- **Theorem 3:** [原文] Eqs. (15),(16) 下 hostile-target AS encirclement error mean-square exponentially converges to region `ε_2`（PDF pp. 6–7）。
- **Guarantee type:** [AI判断] bounded state-estimation + encirclement error convergence under stochastic-noise assumptions；Definition 2/Case 3 定义并执行 radius contraction，但 theorem没有量化“∀ hostile control, finite-time physical contact”。
- **Interception trigger:** estimated distance between protected and hostile targets crosses predefined zones；是 hybrid/sequential switching。
- **Who intercepts:** 固定两 guardian；无 recruitment/assignment。

## 5. Evidence
- **Simulation:** [原文] 两 guardians + cooperative ground target + hostile；展示 control constraints、estimation errors、从 protected target切到 hostile target的 encirclement。
- **Real-world UAV experiment:** [原文] Sec. 4 / Figs. 6–7：1 ground patrolling vehicle、2 guardians、1 hostile target；logging 20–25 Hz、约 6000 samples、不到 1 min。
- **Observed sequence:** [原文] 起初 guardians围 protected target；约第2500次 measurement检测 hostile并形成 defensive barrier；3000–5000围绕 hostile；随后 close in，**neutralizing the threat through direct impact**。
- **Onboard/offboard dependence:** [原文] 论文系统假设 noisy range来自 onboard sensor、自定位可由 VIO/optical flow；结论称无需 external ground guidance。实验节没有像 P0010 那样完整列出 localization/compute infrastructure，因此 [AI判断] 不应额外声称 fully onboard compute beyond paper evidence。

## 6. Limitations

### Author-stated [原文]
- self-localization accumulated error被忽略；
- estimator依赖 noise/process covariance有正定上下界、PE/observability conditions；
- controller为固定两 guardian架构。

### Evidence-visible [原文 + AI判断]
- hostile虽 non-cooperative/可大机动，但运动是 stochastic model，不是对方最优策略。
- range-only原始 observation最终被 KF 转换成 full position/velocity estimate；control不是直接在 unobserved belief中行动。
- two-guardian communication + common frame/self-localization是关键条件。
- formal “capture”以 `r≤r_c` 定义；physical direct impact在 experiment里发生，但 theorem主要保证 estimation/encirclement errors。
- 完成 hostile neutralization后，没有 guardian release、return-to-patrol/coverage 或 repeated threat arrival。

### Our inference [AI判断]
- “classical encirclement cannot transition to actual interception” 已经不成立，且 P0012 不只是 simulation：它有 physical direct-impact demonstration。
- 但 P0012并未替代 P0028 的 strategy-quantified no-escape guarantee；两者解决不同 bridge。
- P0012同时证明“range-only/noisy perception + interception”也不能作为 CoCap 单独 novelty。

## 8. Relation to CoCap
- **Closest similarities:** local/raw partial target measurement、moving target、uncertainty、physical UAV interception、phase switching。
- **Fundamental differences:** 固定2-agent coalition；无 coverage/search；无 multi-target assignment；target state被 filter重建；无 post-capture release；无 repeated arrivals。
- **Does it cover a candidate novelty?** [AI判断] 覆盖 noisy-range sensing、estimation-aware encirclement、encirclement→interception、real aerial impact；不覆盖 dynamic support recruitment/lifecycle。
- **Directly reusable ideas:** active-motion-for-observability；range-difference linearization/KF；threat-distance hybrid mode gate；encirclement contraction schedule。
- **Non-transferable assumptions:** exactly two guardians、known protected-target state、common-frame/self-localization、stochastic rather than strategic hostile。
- **New research questions exposed:** CoCap可否把 observability/estimator uncertainty直接送入 coalition capturability `C(S,j)`，使“需要几名 support”随 belief quality变化。

### P0012 vs P0028
- **P0012 [原文 + AI判断]:** `noisy range → active PE → KF state estimate → zone-triggered hostile encirclement → scheduled radius contraction → physical impact demo`。formal theorem聚焦 estimation/encirclement bounded convergence。
- **P0028 [R-PE-01]:** `speed-aware occupied-angle closure → no escape gap → maintained enclosure → radial inward hunting → capture radius`，并在强几何/速度条件下对自由移动 faster evader给 strategy-independent sufficient capture guarantee。
- **Boundary:** P0012 是 **perception/control/interception bridge**；P0028 是 **game/no-escape/capture-guarantee bridge**。两者都使“ring alone = capture”失效，但保证语义不能互换。
