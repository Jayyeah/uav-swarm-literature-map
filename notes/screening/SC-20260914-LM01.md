## Executive result

[AI判断] The strongest result of this SCREEN is that the learning branch should **not** be organized primarily by backbone names (`MADDPG / MAPPO / QMIX / Transformer`). A more faithful pursuit-specific map is organized by **which classical assumption is relaxed or which missing system layer is learned**:

1. **decentralized policy execution under vehicle constraints** — P0032;
2. **search/tracking role decomposition and multi-target UAV pursuit** — P0033, but with fixed roles and target-state propagation;
3. **literal local FOV / range / urban occlusion** — P0034;
4. **variable-cardinality multi-target encirclement and target prioritization** — P0035, but with global target broadcasting;
5. **unknown clutter + trajectory prediction + physically meaningful CTBR + sim-to-real** — P0036;
6. **classical PE geometry as a learning scaffold** — P0037, and more weakly P0038;
7. **strategic opponent distribution learning through self-play** — P0040;
8. **explicit differentiable target allocation coupled to subgroup pursuit/control** — P0042.

[AI判断] Classical PE/control is not displaced by these papers. It already solves important low-dimensional, model-known, structured-information problems with explicit capture/winning/barrier/assignment objects. RL contributes most credibly when the bottleneck is **high-dimensional physical dynamics, partial/occluded sensing, changing entity cardinality, learned opponent distributions, joint allocation-control coupling, or deployment-oriented policy synthesis**. Several papers still retain strong classical conveniences—global target broadcast, full teammate states, scripted evaders, centralized critics, motion capture, or offboard computation.

## P0032 — Decentralized Multi-Agent Pursuit Using Deep Reinforcement Learning

### Bibliographic identity / publication verification
- Cristino de Souza et al., *IEEE Robotics and Automation Letters*, 2021, 6(3):4552–4559.
- DOI: `10.1109/LRA.2021.3068952`; arXiv: `2010.08193`.
- [Web核验] Formal RA-L publication and open manuscript verified.

### Task
- [原文] Multiple homogeneous pursuers vs **one faster omnidirectional reactive evader** in a bounded 2-D arena.
- Terminal capture: proximity of any pursuer to the evader; no encirclement requirement and no post-capture task.
- Up to eight pursuers in simulation; proof-of-concept physical test with three pursuer drones and a human-controlled target.

### Observation
- [原文] Egocentric relative representation contains the target and **every other pursuer**; sensing is treated as ground-truth and has no literal finite FOV/range/occlusion model.
- [AI判断] “Local coordinates” here do **not** mean CoCap-style local enemy observability.
- State dimension changes with team size; policies are trained for specific pursuer counts rather than one permutation/cardinality-general policy.

### Communication / CTDE / execution
- [原文] No inter-agent communication is required by the learned policy; agents share experience during training and execute the shared policy independently.
- [原文] Real demonstration uses indoor motion capture; behavior is computed on a computer and commands are transmitted wirelessly to the drones.
- [AI判断] Algorithmic decentralized execution is real; **onboard decentralized deployment is not demonstrated**. The authors themselves note the physical implementation resembles a centralized system despite the policy structure.

### Dynamics / action / opponent
- [原文] Pursuer is nonholonomic/unicycle constrained; TD3 learns angular/velocity control variants.
- Evader is **reactive/scripted**, not learned or self-play strategic.

### Evidence / code
- Simulation + small physical proof-of-concept.
- Public code was not independently verified in this SCREEN.

### Actual pursuit-specific contribution
- [AI判断] Historical pursuit-RL turning point: demonstrates that a shared continuous-control policy plus curriculum can produce split-up/ambush-like cooperative behavior under nonholonomic constraints and decentralized policy execution, with a physical-agent demonstration.

### Strongest limitation
- Globally complete relative entity sensing in simulation; single target; no obstacles; count-specific policy; mocap/offboard physical experiment.

### CoCap relation
- Overlap: decentralized policy execution, multiple pursuers, continuous vehicle-constrained motion.
- Novelty threat: medium on “decentralized learned pursuit”; weak on local enemy sensing, multi-target allocation, persistent coverage or onboard autonomy.
- Reusable: ego-centric state construction, curriculum, shared-experience training.

### Recommendation
- **MUST READ** — pursuit-RL genealogy + early physical/decentralized-execution milestone, but cite its deployment assumptions precisely.

- [原文] Targets/evaders are learned competitors in the simulation and have a speed advantage.

### CTDE / decentralization
- [原文] MADDPG-family centralized critics use joint observations/actions during training; actors execute separately.
- [AI判断] “Decentralized” primarily refers to actor execution / distributed team behavior, not absence of global training information or absence of target-state communication.

### Dynamics / environment / real deployment
- [原文] Simulation is based on the Multi-Agent Particle Environment with 2-D continuous motion and obstacles.
- [原文] Crazyflie-based physical demonstration uses external computation, radio communication and UWB/Loco-style positioning infrastructure.

### Allocation / roles
- [原文] `Scout` and `pursuer/tracker` are **preassigned heterogeneous roles**.

### Evidence / code
- Simulation + real Crazyflie demonstration.
- Public code not independently verified in this SCREEN.

### Actual pursuit-specific contribution
- [AI判断] Important problem-definition predecessor: combines exploration-oriented scouts, tracking pursuers, multiple evasive targets and a real heterogeneous UAV swarm demonstration.

### Strongest limitation

### CoCap relation
- Overlap: multi-UAV, multi-target simulation, exploration/scout vs tracking roles, obstacles, real demonstration.
- Novelty threat: **high for broad “search/scout + multi-target pursuit” wording**, but substantially lower for `dynamic support recruitment + genuinely local target sensing + persistent coverage + post-capture recovery`.
- Reusable: explicit separation of exploration and pursuit reward structures; heterogeneous-team baseline.

### Recommendation

## P0034 — Multi-UAV Cooperative Pursuit Strategy With Limited Visual Field in Urban Airspace: A Multi-Agent Reinforcement Learning Approach

- Zhe Peng, Guohua Wu, Biao Luo, Ling Wang.
- *IEEE/CAA Journal of Automatica Sinica*, 2025, 12(7):1350–1367.
- DOI: `10.1109/JAS.2024.124965`.
- [Web核验] Formal journal article and supplementary material verified.

### Task
- [原文] Multiple pursuer UAVs vs **one unauthorized UAV** in urban obstacle fields.
- The episode has `search → pursuit`; if visual contact is lost it transitions to reacquisition behavior around the latest lost point.
- [AI判断] Search is not a persistent coverage task: after first discovery the system is pursuit/reacquisition oriented, not `capture → resume coverage`.

### Target / evader
- [原文] Evaluation includes multiple evader strategies: random motion, repulsive-force/reactive behavior, and a separately trained DDPG evader.
- [AI判断] It therefore tests against a learned evader, but is not bilateral self-play/co-evolution.

### Observation
- [原文] Limited FOV is literal: **finite perception distance + viewing angle + building occlusion**.
- [原文] Unauthorized-UAV position is available only after it is inside at least one pursuer FOV.
- [原文] Actor observations include own state/obstacles, relative information for allied pursuers, and target-relative information in pursuit mode.
- [原文] Once one pursuer detects the target, it **shares the evader coordinate with the other pursuers**.
- [AI判断] Enemy discovery is genuinely local/occlusion-limited, but enemy state after discovery becomes team-shared; this is not “each pursuer only knows enemies it personally senses.”

### CTDE / communication
- [原文] Centralized training / decentralized actor execution.
- [原文] Supplement global state used by the critic contains states of all pursuers **and the evader**.
- [AI判断] Strong example of why “decentralized execution” must be kept separate from “local sensing” and “limited target-state communication.”

### Dynamics / action / environment
- [原文] Continuous motion control with acceleration/angular-motion style commands; simulated urban airspace/building geometry and collision avoidance.
- Formal evidence is simulation, not real UAV deployment.

### Allocation / roles
- No multi-target assignment; all agents cooperate on one target.

### Capture
- Terminal pursuit/capture is proximity based rather than a multi-agent enclosure condition.
- `NEEDS_FULLTEXT`: exact threshold/termination equation should be lifted during READ if used as a baseline implementation.

### Evidence / code
- Rich simulation + supplementary details; no public code verified in this SCREEN.

### Actual pursuit-specific contribution
- [AI判断] Task-defining assumption turning point: RL handles pursuit when target visibility is truly intermittent because of range/FOV/urban occlusion, while a graph-attention critic exploits team structure during centralized training.

### Strongest limitation
- Single target; team-wide target-coordinate sharing after any detection; centralized critic sees global evader state; no real deployment; no persistent coverage/recovery.

### CoCap relation
- Overlap: literal local enemy detection, occlusion, obstacles, decentralized actors, continuous action.
- Novelty threat: **very high** against any claim that local/FOV target sensing itself is novel.
- Reusable: explicit search/pursuit/reacquisition state semantics and occlusion-aware sensing simulator.

### Recommendation
- **MUST READ** — direct task-assumption competitor and one of the most important CoCap-near papers.

## P0035 — TERL: Large-Scale Multi-Target Encirclement Using Transformer-Enhanced Reinforcement Learning

### Bibliographic identity / publication verification
- Heng Zhang, Guoxiang Zhao, Xiaoqiang Ren.
- IROS 2025, pp. 13438–13445.
- DOI: `10.1109/IROS60139.2025.11246832`; arXiv: `2503.12395`.
- [Web核验] Formal IROS publication traced from the open preprint; public GitHub repository verified.

### Task / cardinality
- [原文] Multi-pursuer / **multi-target encirclement**. Training curriculum reaches 15 pursuers / 4 evaders; evaluation scales to much larger teams including 80/20 without retraining.
- [原文] A target is considered encircled only after a multi-pursuer spatial criterion is satisfied; encircled targets are immobilized and pursuers continue to the remaining targets until all are handled.
- [AI判断] This is persistent **within the capture set** (continue to uncaptured targets), but not post-capture return to coverage/search.

### Target / evader
- [原文] Evaders use an APF-style heuristic and are faster than pursuers.
- **Heuristic evasive, not learned/self-play strategic.**

### Observation / communication
- [原文] Teammates and obstacles are observed within a fixed perceptual radius.
- [原文] **All non-encircled evader positions are observable regardless of distance.** The paper explicitly motivates one-way target broadcasting as a practical alternative to inter-agent communication.
- [AI判断] Therefore TERL is **not** evidence for local enemy sensing even though teammate/obstacle perception is local.

### Transformer input / target selection
- [原文] Entity representation includes ego, nearby teammates, nearby obstacles and all active evaders; type-specific encoders feed self-attention.
- [原文] The target-selection module uses pooled relational features and attention over evader representations to emphasize targets.
- [AI判断] This is **adaptive target selection/prioritization**, not a hard capacity-constrained assignment with explicit subgroup membership guarantees.

### CTDE / dynamics / action
- [原文] Global information is used for reward design during training; execution is based on each robot’s observation.
- [AI判断] Do not relabel it as a centralized-critic method without evidence; the core value-based implementation is IQN-like/distributed policy learning.
- [原文] 2-D acceleration/angular-velocity style **discrete** action set; bounded arena, static obstacles and disturbance fields.

### Scalability / generalization
- [原文] Zero-shot scale tests increase both pursuer and target counts, including 80 pursuers / 20 targets, without retraining.
- [AI判断] The 80/20 result is meaningful **variable-cardinality coordination/representation generalization**, but under the same target-motion family and with globally available target positions. It is not evidence of local-sensing or strategic-opponent generalization.

### Evidence / code
- Simulation; public code verified. No real UAV deployment.

### Actual pursuit-specific contribution
- [AI判断] Strong multi-target RL frontier: entity-wise Transformer representation + target prioritization + encirclement reward/collision logic makes one learned policy scale far beyond its training cardinality.

### Strongest limitation
- Global target visibility/broadcast, heuristic APF targets, abstract/discrete motion interface, no real UAVs, no explicit capacity-constrained allocation.

### CoCap relation
- Overlap: multi-target encirclement, variable entity count, target selection, collision/obstacle interaction, continue after individual target encirclement.
- Novelty threat: **very high** against broad claims about multi-target Transformer pursuit, learned target selection, or large-team generalization.
- Reusable: masked variable-entity Transformer, target-prioritization head, count-generalization protocol.

### Recommendation
- **MUST READ** — direct credible CoCap novelty threat and scaling/selection turning point.

## P0036 — OPEN: Online Planning for Multi-UAV Pursuit-Evasion in Unknown Environments Using Deep Reinforcement Learning

### Bibliographic identity / publication verification
- Jiayu Chen et al., *IEEE Robotics and Automation Letters*, 2025, 10(8):8196–8203.
- DOI: `10.1109/LRA.2025.3583620`; arXiv: `2409.15866`.
- [Web核验] Formal RA-L publication, project page, code and videos verified.

### Task
- [原文] Multiple quadrotors pursue **one faster evader** in unknown 3-D obstacle environments.
- Terminal capture is proximity based; no target allocation and no post-capture task.

### Target / evader
- [原文] The evader is explicitly **non-strategic** and follows a potential-field style reactive motion rule.
- [AI判断] OPEN is a deployment/physical-control frontier, not evidence that MAPPO solved strategic adversary co-evolution.

### Observation / communication
- [原文] Line-of-sight is blocked by obstacles. Target-relative state is masked when the evader has not been detected by the team.
- [原文] Once detected, UAVs can pass target information to teammates; the actor also uses teammate-relative state and a small set of nearest-obstacle relative states.
- [原文] An LSTM trajectory-prediction module uses target history/team motion context to predict future target states.
- [AI判断] Occlusion is real, but post-detection target information is team-shared rather than strictly personal local sensing.

### CTDE / action / dynamics
- [原文] MAPPO-family training with shared decentralized policy.
- [原文] Calibrated 6-DOF quadrotor dynamics and motor-response effects; policy outputs **Collective Thrust and Body Rates (CTBR)**, followed by low-level control.
- [AI判断] This is much closer to physical execution than point-mass/velocity actions.

- [原文] Adaptive environment generation varies obstacle layouts and initial conditions; zero-shot tests include unseen obstacle settings and target speeds.

### Real deployment
- [原文] Three Crazyflie 2.1 quadrotors are deployed zero-shot; motion capture supplies quadrotor state; a **virtual evader** is used; policy/prediction run on a local computer and commands are transmitted to the vehicles.
- [AI判断] Strong sim-to-real evidence for pursuit control, but not onboard vision/localization/inference autonomy.

### Evidence / code
- Simulation + physical quadrotor tests; project/code verified.

### Actual pursuit-specific contribution
- [AI判断] Major deployment milestone: combines partial/occluded observations, target prediction, unknown clutter, realistic low-level UAV action and zero-shot hardware transfer.

### Strongest limitation
- Single non-strategic target; team-shared target information after detection; mocap + offboard computation + virtual target in real test.

### CoCap relation
- Overlap: multi-UAV, partial occlusion, obstacles, continuous physically meaningful action, real UAV execution.
- Novelty threat: high against “realistic dynamics / CTBR / sim-to-real pursuit” claims; low against multi-target allocation or strategic evaders.
- Reusable: CTBR interface, hardware calibration/domain randomization logic, prediction-attention under target loss, environment curriculum.

### Recommendation
- **MUST READ** — major real-UAV / physical-action pursuit milestone.

## P0037 — Apollonius partitions based pursuit-evasion strategies via multi-agent reinforcement learning

### Bibliographic identity / publication verification
- Lei Xue, Qing Wang, Yongbao Wu, Xin Yuan, Jian Liu.
- *Neurocomputing* 630 (2025):129643.
- DOI: `10.1016/j.neucom.2025.129643`.
- [Web核验] Formal publisher full article verified.

### Task / opponent / information
- [原文] Multiple faster pursuers vs **one slower sensible evader**.
- [原文] Position and speed information are shared; strategies are private.
- [原文] Evader is model-based: it uses the current global Apollonius dominant region and moves toward a far safe point to prolong lifetime.
- **Strategic/model-based, not learned/self-play.**

### What Apollonius geometry actually does
- [原文] Apollonius circles partition the **state space into dominance regions**.
- [原文] The evader strategy is generated from the dominant region; pursuers seek to shrink that region.
- [原文] A potential-game model and Nash-equilibrium existence argument are built on this structure.
- [原文] Geometry also determines neighbor/role structure used by the role-based backbone QMIX and shapes the cooperative objective/reward.
- [AI判断] This is a **genuine theory-guided RL bridge**, not merely adding an Apollonius scalar feature to a generic network.

### CTDE / dynamics / environment
- [原文] QMIX uses centralized training and distributed execution; pursuer input includes pursuer–evader observation and previous action, while the learning structure accounts for joint effects.
- Simple bounded planar motion; simulation only; no clutter/occlusion/local enemy sensing.
- `NEEDS_FULLTEXT`: extract the exact discrete action set and the exact temporal rule for role/backbone reassignment if implementing this baseline.

### Allocation / roles
- Single target, so there is **no target allocation**.
- Role allocation is pursuit-geometry/neighbor based, not coverage/support recruitment across targets.

### Actual pursuit-specific contribution
- [AI判断] Shows one principled way to use classical PE dominance geometry to provide the game objective, role structure and opponent model while RL supplies cooperative control decisions.

### Strongest limitation
- Much of the hard pursuit structure is supplied by global-state Apollonius geometry; assumptions remain simple/full-information and the evader is deterministic model-based.

### CoCap relation
- Overlap: useful for capture-support role design and geometry-aware reward/state shaping.
- Novelty threat: high against any claim that combining Apollonius/dominance geometry with MARL is new; low on local sensing/multi-target/real deployment.
- Reusable: dominance-area margin as a capturability/support signal; geometry-derived role prior.

### Recommendation
- **MUST READ** — strongest screened theory↔RL bridge.

## P0040 — AgilePE: Autonomous UAV Pursuit-Evasion via Self-Play Reinforcement Learning

### Bibliographic identity / publication verification
- Wenhao Tang et al., arXiv: `2608.14135`, submitted 2026-08-14.
- [Web核验] **Preprint only** as of 2026-09-14; no formal venue verified.

### Task / cardinality
- [原文] **1v1** aerial pursuit-evasion in a bounded 3-D arena.
- Pursuer minimizes separation while keeping the evader in a forward conical FOV; evader attempts to break visual contact and increase separation.
- [原文] FOV and obstacle occlusion mask the opponent state; episodes terminate on timeout, out-of-bounds or close-contact/collision conditions.
- [AI判断] This is a tactical 1v1 pursuit/evasion benchmark, not swarm encirclement, target allocation or persistent coverage.

### Opponent / self-play
- [原文] Both pursuer and evader are learned.
- [原文] The training lineage is naive self-play → fictitious self-play (historical opponent pool) → **Prioritized Fictitious Self-Play (PFSP)** using performance/failure-based opponent sampling.
- [原文] Cross-evaluation of historical policies is used to expose collapse/forgetting and robustness.
- [AI判断] This is the strongest screened evidence that RL adds something classical fixed-opponent designs do not: **learning against a changing distribution of strategic opponents while reducing co-evolution cycling/catastrophic forgetting**.

### Observation / communication
- [原文] Each agent observes own pose/attitude/velocity/action history plus a temporal window of opponent state, masked outside FOV or under occlusion.
- 1v1 means swarm communication/allocation is not addressed.

### Dynamics / action
- [原文] 6-DOF rigid-body UAV model; direct **CTBR** action `[collective thrust, body-rate x/y/z]`.
- [原文] Hardware-aligned simulator models actuator latency/noise and applies domain randomization.

### Real deployment
- [原文] Zero-shot physical two-quadrotor pursuit/evasion is reported; the paper figure explicitly identifies a **motion-capture arena**.
- [Web核验] The abstract describes onboard-state-to-CTBR policy execution and real interactive deployment.
- `NEEDS_FULLTEXT`: before making a strong “fully onboard autonomous sensing/localization/inference” claim, record the exact motion-capture→state-estimation→compute→PX4/control architecture from the deployment section. Motion capture means the experiment should not be described as vision-only local perception.

### Evidence / code
- Large-scale simulation + physical 1v1 flight; no formal peer-reviewed publication yet.
- Public code was not independently verified in this SCREEN.

### Actual pursuit-specific contribution
- [AI判断] Frontier combination of strategic bilateral self-play, low-level agile action and zero-shot real flight. It addresses opponent non-stationarity and physical agility rather than swarm allocation.

### Strongest limitation
- Preprint-only; 1v1; state-based/mocap arena; no multi-target/swarm coordination or persistent task.

### CoCap relation
- Overlap: local FOV/occlusion semantics, physically meaningful action, learned strategic opponent, real UAV.
- Novelty threat: **very high** against claims about “first strategic learned evader / self-play / CTBR real-UAV pursuit,” but low on swarm/multi-target/support allocation.
- Reusable: opponent pool/PFSP, historical-policy cross-play matrix, hardware latency/noise modeling.

### Recommendation
- **MUST READ** — strategic-adversary + real-UAV frontier turning point, with publication-status caveat.

## P0042 — Spatially valid underwater target capture by multiple AUVs with dual policy reinforcement learning framework of target allocation and pursuit control

### Bibliographic identity / publication verification

- *Ocean Engineering* 365(P1), 2026, 127180.
- DOI: `10.1016/j.oceaneng.2026.127180`.

### Task / cardinality
- [原文] Multiple AUVs vs **multiple maneuvering targets** in a bounded 3-D underwater workspace with uniform current disturbance.
- [原文] Agents form target-oriented subgroups and continue until all targets are captured.

### Allocation / subgroup structure

# Cross-paper synthesis

## 1. What classical methods already solve

[AI判断] Based on this LM SCREEN together with the PE/encirclement skeleton already in `main`, classical methods already provide:

- capture/winning/barrier/dominance objects under explicit dynamics/information assumptions;
- Apollonius/Voronoi-style interception and dominance geometry for simple motion;
- encirclement/formation and collision/safety controllers with provable structure;
- pairwise capture certificates and matching/optimization-based target/coalition assignment;
- optimal/control-game solutions when the state dimension, model uncertainty and information pattern remain tractable.

Therefore CoCap should **not** claim that RL uniquely enables cooperative pursuit, encirclement, multi-pursuer capture, target assignment, decentralized control, or local sensing in the broad sense.

## 2. What RL actually adds in the screened lineage

[AI判断] The defensible additions are narrower and stronger:

1. **Policy synthesis under high-dimensional dynamics** where direct HJI/analytic control is impractical — especially CTBR/6-DOF work (P0036, P0040).
2. **Learning under intermittent/partial perception and clutter** while integrating prediction or neighbor aggregation (P0034, P0036, P0038).
3. **Variable-entity relational reasoning and cardinality scaling** (P0035).
4. **Adaptive target prioritization / differentiable allocation coupled to continuous control** instead of a fully hand-separated allocator and controller (P0035, especially P0042).
5. **Opponent-distribution learning** rather than optimizing against one prescribed evader (P0040; partially P0033).
6. **Curriculum / environment generation / domain randomization** to cross sparse-exploration and deployment gaps (P0032, P0036, P0040).
7. **Hybrid theory→learning scaffolds** where PE geometry supplies dominance/capture structure and RL learns control (P0037; P0038).

[AI判断] A recurring surprise is that RL papers often relax **one** hard assumption while retaining another: FOV but target broadcast; real dynamics but non-strategic evader; multi-target scaling but globally known targets; self-play but only 1v1.

## 3. Strongest current CoCap-near competitors

Ranked by structural overlap, not venue prestige:

1. **P0042** — strongest structural threat: explicit multi-target capacity allocation → subgroups → continuous pursuit → spatially valid capture, with local actor observations; cross-domain AUV and sensing/comm details still need normalization.
2. **P0035 TERL** — strongest UAV/swarm multi-target encirclement + variable-cardinality target-selection/scaling threat, but target positions are globally broadcast and evaders are APF heuristics.
3. **P0034 Peng 2025** — strongest literal local-FOV/range/building-occlusion threat; weakened by one target, team-wide target sharing after detection and global-state critic.
4. **P0033 Kouzehgar 2023** — strongest older `scout + pursuer + multi-target + real UAV` predecessor; weakened by fixed roles, target-location propagation, tracking semantics and single-target real demo.
5. **P0036 OPEN** — strongest physical-action/unknown-obstacle/real-UAV neighbor; weakened by one non-strategic target, team-shared detection and mocap/offboard/virtual-target deployment.

Adjacent but not top-5 by full CoCap overlap:
- P0038 is the cleanest local-observation + limited-neighbor-communication single-target competitor.
- P0040 is the strongest strategic-opponent/physical-action competitor, but 1v1.

## 4. CoCap novelty statements that are no longer safe

[AI判断] Do **not** claim any of the following without a much narrower qualifier:

- “first multi-UAV multi-target RL pursuit/encirclement” — contradicted by P0033/P0035 and adjacent literature.
- “first local / limited-FOV / occlusion-aware MARL pursuit” — contradicted by P0034 and P0038.
- “first decentralized-execution UAV pursuit with RL” — P0032 and later works precede it.

# Strongest assumption surprises

1. **P0032:** “decentralized” is valid at policy-execution level, but the physical demo uses mocap + external computation/wireless commands; local representation is not finite-range local sensing.
2. **P0033:** scout/tracker roles are preassigned, not dynamic switching; target locations are propagated over the communication network; real demo is single-target.
3. **P0034:** limited FOV/building occlusion is genuine, but after any pursuer detects the target, its coordinate is shared across the team; centralized critic sees global pursuer+evader state.

5. **P0036:** highly realistic CTBR/obstacle/sim-to-real work still uses a **non-strategic APF evader**; real test uses mocap, a virtual target and offboard computation.
6. **P0037:** Apollonius geometry is not decorative feature engineering—it drives dominance regions, evader strategy, role/neighbor structure, potential-game objective and reward logic.
7. **P0038:** Apollonius geometry is more limited than in P0037: mainly a capture/judgment boundary, while GAT/QMIX handle local perception/control.
8. **P0040:** self-play genuinely attacks strategic-opponent non-stationarity, but the evidence is **1v1**, not swarm/multi-target.
9. **P0042:** despite being AUV work, its explicit capacity-constrained assignment + subgroup control + spatial capture pipeline is structurally closer to CoCap than many UAV papers.
