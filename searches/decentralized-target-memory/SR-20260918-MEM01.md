## SCOPE

### Research question

This focused search asks:

> Under local/intermittent observation in pursuit, interception, tracking, or swarm response, how do agents preserve, propagate, decay, or predict recent target evidence, and does that temporal information control pursuit continuation, subgroup response, release, or return to a nominal task?

The search is deliberately narrower than generic recurrent MARL. It targets the mechanism boundary exposed by CoCap B1:

- B0 Final IQN uses an environment-maintained effective pursuit bit as a policy input.
- B1 removes that shortcut but keeps the rest of the observation/reward contract as matched as possible.
- The no-bit student still achieves mixed capture in 3/3 matched rollouts, but loses stable post-capture recovery and pure coverage; support is the worst offline role subset.
- A calibrated cross-role near-observation audit points toward missing target-recent-memory / local-target-evidence information rather than a need to restore the artificial role bit.
- Therefore the search target is physical/temporal evidence, not a generic hidden role label.

- Temporal memory type: explicit spatial target-evidence field
- RNN/GRU/LSTM/history: no neural recurrent memory; memory is externalized into digital pheromone

- Prediction model: diffusion/probability trace rather than learned trajectory prediction

- Real experiment: human-operator experiments on the simulated system; authors explicitly say no testbed for the fully autonomous system
- Why relevant to CoCap B1/B3: this is the closest broad mechanism antecedent to a scalar local activation that propagates and evaporates while trading response against surveillance
- Likely priority: Tier A — MUST SCREEN

### MEM-A2 — Decentralized End-to-End Multi-AAV Pursuit Using Predictive Spatio-Temporal Observation via Deep Reinforcement Learning

- Authors: Yude Li, Zhexuan Zhou, Huizhe Li, Yanke Sun, Yenan Wu, Yichen Lai, Yiming Wang, Youmin Gong, Jie Mei
- Year / venue: 2026, IEEE Robotics and Automation Letters 11(7):8712-8719
- DOI / arXiv: 10.1109/LRA.2026.3700665 / arXiv:2603.24238
- Publication status: published, 5 Jun 2026
- Task: multi-AAV cooperative pursuit/encirclement/capture in clutter
- Target cardinality: tested primarily Nv1
- Observation locality: egocentric PSTO + onboard LiDAR for obstacles
- Occlusion/intermittency: yes; predictor explicitly maintains continuity when evader is not observable
- Temporal memory type: LSTM target trajectory predictor + previous-step predicted target position
- RNN/GRU/LSTM/history: LSTM history of effective evader position
- Explicit belief: no explicit Bayesian belief; predictive latent/trajectory state
- Last-seen state: not a simple last-seen feature; observed target is replaced by the previous prediction when unseen
- Prediction model: multi-step future evader waypoints; teammate future trajectories by linear extrapolation
- Information age/decay: predicted future points use temporal factor lambda_e^k; this decays prediction-horizon attraction, not stale-evidence age/TTL

- Target-loss semantics: previous prediction substitutes for missing observation
- Release/return semantics: none; episode remains a pursuit/capture task
- Scale/generalization: same policy evaluated across 2v1, 3v1, 4v1 without retraining
- Real experiment: fully autonomous outdoor quadrotor swarm with onboard sensing/compute
- Why relevant to B1/B3: strongest recent pursuit-specific evidence that temporal prediction, rather than an artificial role bit, can preserve pursuit continuity
- Likely priority: Tier A — MUST SCREEN

Important normalization:
[原文] The paper calls the policy decentralized, but the evader observation used by PSTO is available when any pursuer observes the evader. [AI判断] Therefore it is strong M2/M3 temporal evidence but not strict CoCap-style local-neighbor target-evidence propagation.

## MEMORY TAXONOMY

Proposed compact taxonomy for MASTER review; SEARCH child does not edit the global taxonomy.

### M0 — Memoryless local observation

Only current-frame/current-step sensing enters the decision.

Examples/near examples:
- purely reactive pursuit baselines;
- P0038/GERL are primarily spatial neighbor aggregation at SEARCH depth unless full SCREEN reveals a hidden temporal channel.

### M1 — Explicit recent-target feature

Physical interpretable target recency is part of state:
- last-seen position;
- last-seen velocity;
- time since seen;
- timestamp;
- last-known covariance/quality.

Examples:
- P0034: lost point + t_lost.
- MEM-A4: last-known target state + timestamp + covariance.
- MEM-A6: last observed target state + elapsed time since last observation.

### M2 — Recurrent latent memory

A recurrent encoder carries history without requiring explicit handcrafted recency fields.

Examples:
- MEM-A2: LSTM evader history.
- MEM-A3: Bi-GRU temporal observation encoding.
- MEM-A6: LSTM memory units.
- MEM-B1: compressed learned historical belief, architecture to verify at SCREEN.

### M3 — Predictive temporal state

Memory is converted into a target trajectory, intent, occupancy/belief, or uncertainty prediction used for control.

Examples:
- MEM-A2: previous prediction -> future LSTM waypoints.
- MEM-A3: behavior-mode/subgoal inference -> calibrated trajectory prediction.
- MEM-A4: particle-filter target distribution from last-known state.
- MEM-A6: opponent model predicts current target state and uncertainty.
- MEM-B2: possible-position belief preservation.

### M4 — Local shared evidence

Target-related evidence is propagated through a local neighbor mechanism rather than immediate team-wide broadcast.

Forms:
- peer-to-peer neighbor messages;
- graph-neighbor fusion;
- event-triggered local broadcasts;
- stigmergic spatial fields.

Examples:
- MEM-A1: local alarm-pheromone diffusion.
- MEM-A5: neighbor-to-neighbor target perception/estimate exchange.
- P0038: neighbor feature aggregation, although target-specific semantics need SCREEN.

### M5 — Decaying distributed belief

Strict working definition for this search:

local held target evidence
+ local propagation/fusion
+ explicit temporal obsolescence/uncertainty growth/forgetting
+ decision use.

Two strong broad precedents were found, but neither is the exact CoCap system:

1. MEM-A1 — behaviorally reaches M5:
   - local target-triggered alarm field;
   - local diffusion;
   - explicit evaporation;
   - pursuit/reacquisition while evidence persists;
   - return to patrol when evidence disappears.
   - caveat: stigmergic shared environment, explicit controller modes, simulation-centered, no true terminal capture loop.

2. MEM-A4 — estimation/allocation reaches M5-like semantics:
   - per-UAV local target table from own perception/local comm;
   - last-known state + timestamp + covariance;
   - recursive target belief prediction;
   - explicit exponential information-value decay;
   - local/distributed allocation and coalition formation.
   - caveat: staged search-allocation-tracking, not temporary pursuit/support activation and capture-triggered release.

Conclusion:
[AI判断] M5 as a generic mechanism is not new. What remains open is M5 embedded in a strict local, fungible, same-policy coverage/capture lifecycle with terminal capture and measured nominal-task recovery.

## ARTIFICIAL ROLE BIT VS PHYSICAL TEMPORAL EVIDENCE

### 1. Does literature directly provide pursuit mode / role state?

Yes, especially in hybrid/control systems.

- P0048: hand-written Patrol / Pursue Intruder mission arbitrator with a five-minute no-intruder return.
- MEM-A5: explicit Search / Chase / Dock modes triggered by mission events.
- MEM-A1: pursuit is a separate behavior around an alarm field and authority-sharing modes.

Therefore:
[AI判断] Merely replacing an artificial neural-policy role bit with another externally assigned discrete FSM mode would not create a strong method contribution.

### 2. Are there RNN/belief alternatives to a role bit?

Yes.

- MEM-A2: LSTM prediction carries pursuit continuity across occlusion.
- MEM-A3: Bi-GRU + intent/subgoal belief + predictive uncertainty drives maneuver gating.
- MEM-A6: LSTM memory + last seen + elapsed time + target prediction/uncertainty.
- MEM-B1/B2: learned or explicit target belief states under visibility loss.

Therefore:
[AI判断] “use history/RNN/belief instead of a role label” is an established design family.

### 3. Are time-since-detection / confidence features established?

Yes.

- P0034: t_lost expands the suspect area.
- MEM-A4: target timestamp and covariance enter a credibility model with exponential temporal discount.
- MEM-A6: elapsed time since last observation and predicted uncertainty are explicit policy-relevant state.

Therefore:
[AI判断] time-since-seen and confidence are conventional, physically interpretable state variables rather than novelty primitives.

### 4. Is there local propagated scalar/field activation?

Yes in broad form.

- MEM-A1 alarm pheromone is extremely close conceptually:
  detector deposits evidence -> local diffusion -> neighboring agents become attracted -> evaporation -> patrol return.
- MEM-A5 propagates target estimates through local neighbor communication, though not as a single scalar activation.
- P0038 propagates neighbor observation features spatially, but no temporal activation/forgetting was found.

### 5. Does something already look like a decaying z_i?

Broadly yes, but not in the exact CoCap implementation form.

The proposed CoCap rule

z_i^{t+1} = max(d_i^t, lambda z_i^t, eta max_{j in N_i^t} z_j^t)

combines three old ingredients:
1. direct target evidence;
2. temporal persistence/decay;
3. local-neighbor propagation.

Each ingredient and their broad combination already have precedents:
- direct detection + local propagation + evaporation: MEM-A1;
- local target table + age/uncertainty + exponential decay: MEM-A4;
- neighbor target-state fusion: MEM-A5.

No SEARCH result used this exact max-recursion or VorAdj topology. That exact formula is not the right novelty level anyway.

### 6. What claim remains defensible?

Recommended method-positioning implication:

> CoCap should not present decaying target evidence itself as new. The stronger candidate is using a physically interpretable, strictly local and temporally decaying evidence state to replace a privileged role shortcut inside one homogeneous shared policy, so the same fungible swarm can preserve temporary pursuit/support through target intermittency and then release back to measured nominal coverage after terminal capture.

This is best treated as a problem-level / coupling-level contribution, not a first-ever memory mechanism.

## CONFLICTS / UNCERTAINTIES

1. “Decentralized” terminology conflict
- MEM-A2 is a decentralized policy but uses target availability when any pursuer sees the evader and receives teammate states through communication.
- MEM-A3 is framed as a Dec-POMDP/CTDE problem, but its conclusion still names decentralized belief updating as future work.
- Therefore actor decentralization must not be treated as proof of local target belief.

2. “Decay” terminology conflict
- MEM-A2 lambda_e^k decays future waypoint attraction across prediction horizon.
- This is NOT the same as old evidence becoming less trusted as time-since-seen grows.
- MEM-A1 and MEM-A4 are the clean explicit stale-evidence decay precedents.

3. “Capture” terminology conflict
- MEM-A1 uses interception/repeated detection semantics, not CoCap terminal cooperative capture.
- MEM-A4 discusses target recapture/tracking probability; it is a tracking/allocation paper, not a terminal PE-capture lifecycle.
- MEM-A5 concerns search/chase/pre-capture enclosure/dock in spacecraft ADR; this differs from UAV pursuit capture.

4. M5 scope
- MEM-A1 qualifies behaviorally but uses stigmergic field memory, not per-agent peer messages.
- MEM-A4 qualifies in an estimation/allocation sense but not lifecycle response.
- Therefore “M5 exists” should be stated with task/mechanism qualifiers, not as exact CoCap closure.

5. SCREEN depth
- Several 2026 papers are recent enough that citation counts/genealogies are immature.
- Current recommendation is based on mechanism overlap, not citation prestige.
