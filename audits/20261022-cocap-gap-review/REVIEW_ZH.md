# CoCap 文献查缺补漏与 baseline 决策复核

2026-10-22｜面向论文选型，而非泛泛罗列 swarm 文献。

本轮以旧仓库 main `d03e9ff2cbcd1d946cf338079077825737cba93c` 为起点，复核新增的两份附件，并沿局部多目标、密度交互、学习分工、证据衰减及任务恢复四条线补查。这里只公开任务层面的比较，不引入私有项目代码、日志或未发表实验数据。

**结论：保留 TERL，优先预检 AIS 多目标 PGM；DBI 密度交互是较简单的传统备选。FSC2 必须进入核心相关工作。** 上一份八篇报告建议的“TERL + kWTA”可作为起步组合，但不足以独自支撑局部信息条件下的优势。补查后，不能继续使用“局部感知、同质群体、动态搜索/围捕分工的交集尚空白”这一宽泛说法。

这不是发现了完全等同于 CoCap 的论文，也不是证明 CoCap 没有价值。真正需要检验的是：**在有限目标信息、受约束运动和多人几何捕获下，临时支援怎样影响跨目标资源占用及后续覆盖。** 若实验没有证明这些收益，不能只靠列出更多约束形成创新。

## 1. 证据范围及容易混淆的概念

本轮精选名录含 **29 篇**，其中 24 篇补入旧索引、5 篇沿用旧 ID；全库由 51 增至 75 条。25 篇取得原文证据：23 篇以 PDF 取得、2 篇以文章正文网页取得（另保存 JAS 官方补充 PDF）；其中 **22 篇关键文献由主 agent 阅读核查原文**，另外 3 篇仅完成子 agent 全文筛查。22 篇包括此前八篇附件的全文核查记录和本轮新增/重审的 14 篇。其余 4 篇精选候选仍只有预览，未冒充 READ。详见 [名录](COLLECTION.csv)、[来源清单](SOURCE_MANIFEST.csv)、[待核事项](UNRESOLVED.md)。这是定向补漏，**不宣称全领域饱和**。

下文 `[原文]` 指直接证据；`[AI判断]` 指比较、批评或建议。关键条目链接到阅读卡，记录 PDF 物理页或网页章节；“原文报告”不等于我们已复现其结果。

| 必须拆开的维度 | 对选型的实际影响 |
|---|---|
| 本机局部观测 / 邻居转发目标坐标 / 全队共享观测 | 都可能被作者称为 decentralized，但信息能力不同；不通信也可能获得全部目标位置 |
| 自发聚群 / 目标软偏好 / 硬配额匹配 / 捕获可行性证明 | 人数大致分开，不代表配额必满足；满足配额，也不代表当下能抓住目标 |
| 近距接触 / 网格四邻围住 / 多机角度闭合 / 稳定环绕 | 都可能叫 capture 或 encirclement，成功率不能直接横比 |
| 失联超时回巡逻 / 捕获后追剩余目标 / 全部完成后恢复覆盖 / 重复新目标到达 | 是不同强度的任务延续证据，不能合并为一个“完整生命周期”标签 |
| 集中外部定位后局部过滤 / 完全机载局部感知 | 前者可验证局部决策规律，不能作为后者已完成的实物证据 |

对当前文章也应同样严格：共享策略不等于无人工任务结构；使用 Voronoi 邻居不自动保证图构造只用有限半径通信；局部目标坐标不等于所有几何量均局部。本文不把尚未实现的“捕获可行性估计”或“机会成本优化”列作现有贡献。

## 3. 技术版图：真正需要比较的五条路线

### A. 先明确分配，再执行围捕

[原文] [kWTA（P0052）](../../notes/reading/P0052-GAP20261022.md) 用距离竞争、冲突消解和配额补齐分组，再用 OAPM 虚拟力；[JAS TR11（P0058）](../../notes/reading/P0058-GAP20261022.md) 用 A* 绕障代价分组、围捕顶点拍卖及带高斯误差裕度的安全控制；[KS-COAL（P0044）](../../notes/reading/P0044-GAP20261022.md) 用有限长度连锁换岗与共识改善分配，并用图网络加速。

[AI判断] 这条线的优势是组别、配额和控制模块可解释；代价是更强的目标/地图/协调信息及接口复杂度。配额可行、K-serial 稳定、概率避碰分别回答不同问题，都不能直接当成“任何目标最终被捕获”。TR11 的单积分器控制量若量化为受转向约束动作，原安全证明不能继承。KS-COAL 已有捕获后资源再分配，因此“释放重用”本身不是贡献。

### B. 局部密度交互与概率决策：此前遗漏最严重的一支

[原文] [DBI 2023（P0062）](../../notes/reading/P0062-GAP20261022.md) 以 SPH 密度和压力负反馈形成单环、多环或多子群；[TRO ADI 2024（P0063）](../../notes/reading/P0063-GAP20261022.md) 根据目标强度改变参考密度和吸引，使分组人数隐式自适应；AIS/RA-L 则把密度及其他行为写进候选动作的概率似然，通过 MAP 决策。

[AI判断] 不能把这一支统称“知道所有目标后做固定圆形编队”。DBI 有先巡逻再发现的实物实验；ADI 也有巡逻，以及目标被移除后转向剩余目标的实物实验。它们没有因此自动解决均匀覆盖、捕获事件驱动释放及持续服务质量，但已明显压缩了我们可声称的空白。其价值还在于免训练、模型较紧凑，是检验学习到底增加什么的关键对照。

### C. 局部显式招募与图案形成

[原文] [SUNDER（P0065）](../../notes/reading/P0065-GAP20261022.md) 中首次发现目标的机器人临时成为 organizer，通过局部多层招募形成预期大小的小组；共享相对坐标、目标状态及组别，再以 GRN 生成包围图案并避障。角色不是固定硬件类别。

[AI判断] 这是“局部发现后招募队友”的代表，不能只与全局分配器比较后宣布这一机制新颖。它从追逐主目标再遇到新目标展开，稳定占据判据不同于终端多人角度捕获，大规模结果是仿真；完整移植成本偏高。适合解释“显式消息/组标识招募”和“轻量信号支援”的区别。

### D. 学习搜索 + 手工分配/围捕求解器的混合系统

[原文] [FSC2（P0061）](../../notes/reading/P0061-GAP20261022.md) 是强近邻：同质机器人局部网格观测、不通信，学习搜索，模糊局部分配，在线 cooperative coevolution 处理围捕。不同机器人动态处于 searcher/pursuer 状态。

[AI判断] 它同时跨过“同质、局部、多目标、动态分工”，不能被固定角色 MADDPG（P0033）替代。我们与它的有效区分是连续受约束运动、成功事件后可重新使用的捕获者及量化的覆盖恢复；不是“首次让同一机器人有多种角色”。它也提醒我们：不必把全部任务都交给一个端到端网络，混合系统可能更强。

## 4. 三篇优先精读：理论、短板、baseline 价值

### 第一篇：FSC2——先修正创新边界

[原文，PDF pp.4–8] 每个机器人用局部窗口感知目标、队友和障碍。没有自由目标时使用共享搜索策略；看到自由目标时，依据距离构造模糊归属并抽样局部分配。分配后不是由同一 RL 网络包办围捕，而是在线评价可选下一位置：目标是否落入追捕者凸包、距离是否足够小、空间是否均匀，并处理碰撞及局部决策冲突。本地记忆记录已完成捕获和锁定机器人，避免重复占用。

它的核心贡献是将部分可观测的联合任务拆成可协作的搜索、局部分配和单目标求解，使同质个体在无需通信时仍能协调。大规模网格结果体现算法扩展性；不能把网格步长扩大就当作连续无人机可部署性。

[原文，pp.4,10] 正式 SOP 需要四个邻接位置围住目标，目标不消失，参与捕获者锁定；之后其他机器人继续搜索。搜索预训练的触碰后目标消失，是另一个任务，不能混用。

[AI判断] **阅读优先级最高，完整移植优先级低于 AIS/DBI。** 直接改成连续受约束动作，就必须重设计候选位置、冲突约定、捕获记忆及资源释放；这会引入大量作者原文之外的新算法。可先做其原网格任务的忠实复现，再决定是否值得构造明确命名的 continuous-adapted 版本。我们的预期优势应落在捕获者重用、连续多人闭合和更低任务中断上；这些是待检验假设，并非已胜出的结论。

### 第二篇：AIS 多目标 PGM——最应先做的传统复现预检

[原文，pp.4–9] 六节点图以候选动作为中心，将本机搜索痕迹、局部目标/邻机密度、避障和攻击等条件的似然相乘，选择后验最大的加速度。密度由 SPH 核求和估计，参考密度反映期望围捕几何；目标运动预测辅助动作评价。搜索航迹随时间衰减，减少重复走已访问区域。这里的概率图是设计出来的决策模型，不是 GNN 或离线训练的策略。

直观上，密度回答“附近哪里有目标、哪里缺/挤机器人”，概率决策将几个可能冲突的行为折中。论文用 Apollonius 几何分析封堵条件，但不能据此认为完整动态闭环在所有障碍中都有终端捕获保证。

[原文，pp.10,14–15] 同一批机器人抓到目标后重新搜索剩余目标，有多机/多目标/移动障碍仿真与六机两目标实物。外部 mocap 和上位机控制意味着它验证了局部输入后的决策，不代表所有感知和计算都在机载完成。

[AI判断] 它比旧单目标 RAS 更贴近完整任务，也比 kWTA 更贴近局部目标接口。**预检先验证原生候选动作、状态转换与作者目标运动，再接统一动力学。** 其最终攻击/距离触发和我们的 normal capture 不同，须重新计分。我们的潜在优势应是：不依赖目标因受到包围而按特定规则减速，在转向受限、多目标竞争时更有效地补足角度缺口，并保留足够区域覆盖。不能把“有搜索/有捕获后继续工作”写成差异。

### 第三篇：DBI → TRO ADI——用最紧凑的局部规则挑战学习必要性

[原文] DBI 以局部密度及压力误差产生运动，配合机器人间排斥、目标交互和自推进；目标/邻居位置改变密度，机器人由此自行聚群。ADI 进一步把目标强度纳入参考密度和吸引，从而隐式调节各目标资源及多环结构。**异质的是目标，追捕机器人仍可同质。**

两篇都有真实机器人实验，且不能忽略其巡逻到发现、或目标移除后的资源重分配。另一方面，紧凑群体巡逻不是均匀区域覆盖；人为移除目标不是已经核实的终端捕获触发释放闭环。

[原文] DBI 报告过人数失衡与少于三机不能围住的情形，避障仍是后续；ADI 在理论中采用逐个机器人移动的近似，并明确同步系统精确稳定性未解决，实物中也可能遗漏孤立目标。这些是真实限制，不宜扩写为“传统密度法普遍失败”。

[AI判断] **DBI 是 AIS 实现成本过高时的第一备选；ADI 用于理解人数自适应和最新局部传统技术。** 可以先做单/双目标连续几何子任务，验证密度规律，再使用统一搜索/避障适配器比较完整任务。新增模块必须两边一致说明。我们的预期优势是改善资源饿死、过量聚集、任务完成与区域恢复间的折中；若只在专门为 RL 奖励调好的任务中优于未调参的密度法，不能支持这一论点。

额外必读：[W-MAPPO](../../notes/reading/P0068-GAP20261022.md) 的 pp.6–19、29–34。它对全过程叙事威胁很直接，但单机拦截与多人包围的难点不同，当前更适合作为创新边界而非立即移植的主 baseline。论文噪声训练/测试口径存在文字不一致，本综述不重复其鲁棒性百分比作为确定结论。

## 5. “局部证据 + 临时支援 + 恢复”还有多大空间？

[原文] [Legras 2008（P0067）](../../notes/reading/P0067-GAP20261022.md) 已有报警信息素的局部扩散、衰减、临时招募及回巡逻，并明确讨论招募过多损害监视；[Duarte 2014（P0048）](../../notes/reading/P0048-GAP20261022.md) 已有同质资源池、局部报警、同一机器人巡逻—追踪—超时回巡逻及多轮事件；[Wolf 2026（P0066）](../../notes/reading/P0066-GAP20261022.md) 以积累观测/连通证据和迟滞切换搜索、接力、包围角色。

这些不是一条已经逐篇证明的引用传承链，而是**机制对照**。Legras 的 interception 是连续检测，Duarte 是跟踪，Wolf 是单目标稳定包围；Wolf 的全队选举及共享估计接口还有需要代码澄清之处。它们不能证明与 CoCap 同任务已完成，却足够否定“衰减证据第一次带来协作/角色变化”的表述。

| 候选论点 | 当前判断 | 能成立需要什么 |
|---|---|---|
| 首次局部同质多目标搜索/围捕 | **不能使用** | FSC2、AIS、密度路线已构成直接反例 |
| 首次捕获后释放或继续剩余任务 | **不能使用** | TERL、KS-COAL、AIS 等已覆盖不同版本 |
| 首次衰减证据引导招募、角色变化或回巡逻 | **不能使用** | 早期信息素和近期角色状态已有先例 |
| 不转发隐藏目标坐标的轻量支援，提高多人捕获与持续覆盖效率 | **可检验的窄论点** | 明确全部消息与图构造；统一信息预算，比较信号对照及跨目标占用/覆盖指标 |
| 学到了捕获可行性或机会成本最优分配 | **现阶段不能当成果** | 需有对应模型、监督/目标或可证解释，并验证；不能把启发式信号强行解释成估计器 |
| 约束动力学下学习协作优于免训练局部方法 | **可检验的实证贡献** | 与 AIS/DBI 等调参充分的对照，在正常角度捕获、障碍和目标策略上公平检验 |

[AI判断] 较稳妥的文章主线是：**说明轻量局部协作机制如何缓解多人捕获造成的暂时覆盖损失，而不是宣布此前没有集成搜索与捕获。** 把已有模块堆在一起仍不够；需要机制消融、反例场景和效率证据证明为什么值得采用。

## 6. 下一步选型：控制成本，同时保留强对照

| 顺序 | 工作 | 继续/停止依据 |
|---|---|---|
| 1 | 固定任务合同：目标信息、邻居消息、图构造、动力学、normal capture 与异常失活分开计分 | 若合同未固定，先不扩大训练 |

原生复现和共同环境比较应分开报告：前者检验实现忠实；后者才回答当前任务表现。原版允许目标减速/停止的设定可保留在原生核验，但共同环境必须统一逃逸者策略，不能只给某一 baseline 使用“包围后自动减速”的目标。

共同评测除捕获率/时间，应至少记录：正常几何捕获与异常失活、碰撞、未服务目标等待、每目标参与人数及过量占用、捕获后覆盖恢复时间、累计覆盖损失、消息负载和运行成本。有限批完成与新目标持续到达应分别测试；失败/超时不能从时间均值中消失。种子、预算与调参边界要对齐，结果还未产生前不要写“期望优势已证明”。
